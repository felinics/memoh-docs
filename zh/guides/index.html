教程 ​

这些教程从产品使用流程出发，默认你已经能访问 Memoh，需要创建机器人、管理会话、连接工具，并使用日常功能。

开始使用 Memoh ​

  • 快速开始：部署服务端、添加模型、创建第一个机器人并接入渠道。
  • 用户偏好：配置界面语言、主题、字体、图表和快捷键。
  • 机器人：创建机器人并配置核心标签页。
  • 会话：理解 chat、discuss、路由和状态区。
  • 文件：浏览和编辑机器人 workspace 文件。
  • 长期记忆：在配置好记忆提供方后管理长期记忆条目。

扩展机器人能力 ​

  • 技能 和 应用市场：添加可复用提示模块和模板。
  • Hooks 和 MCP：连接工具、自动化规则和外部数据源。
  • Browser / Computer Use：使用有头浏览器和可见桌面会话。
  • 斜杠命令：用命令快捷完成日常控制。

权限与运行 ​

  • 访问控制：配置 ACL 预设、规则顺序和来源限定。
  • Workspace：从产品界面理解 workspace 行为。
  • 上下文压缩：缩小当前会话上下文占用。
  • 计划任务：按 cron 计划运行周期性工作，无需活跃聊天。
  • 邮件：配置邮件相关工作流。

其他文档区域 ​

  • 集成：连接渠道和提供方。
  • 自托管：部署和运维自己的 Memoh 实例。

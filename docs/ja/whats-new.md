### Grok Build を組み込みエージェントとして使う {#2026-10-19-grok-build}

Grok Build が、Codex・Claude Code と並ぶファーストパーティのエージェントとして Memoh に同梱されました。Bot の **エージェント** タブで追加し、Grok アカウントでサインインするか、xAI API Key を入力してください。

Grok Build は組み込みツールに独自の権限モードを適用します：**毎回確認**（既定。副作用のある操作の前に確認）、**自動判断**（安全に実行できる操作を Grok が判断）、**すべて承認** のいずれかです。Grok アカウントでのサインインは、Bot を作成したあとにエージェントの設定から行えます。詳しくは [Agents / ACP](./guides/acp.md#grok-build) を参照してください。

### クラウドデスクトップでコピー＆ペーストし、自分の言語で入力する {#2026-10-19-desktop-input}

テキストを、手元のコンピューターと Bot のデスクトップの間で双方向にコピー＆ペーストできるようになりました。ローカルの入力方式（IME）も使えます：自分のキーボードで日本語や中国語などを入力して確定すると、その文字がデスクトップに入力されます。macOS の編集ショートカットもデスクトップ上でそのまま使えます。

詳しくは [Browser / Computer Use](./guides/browser-computer-use.md) を参照してください。

### スケジュールタスクのセッションをすっきり保つ {#2026-10-19-schedule-sessions}

実行のたびに新しいセッションを作るタスクが、**最近** を埋め尽くすことはなくなりました。**スケジュール** パネルでタスクのカードをクリックすると、各実行で作られたセッションが一覧され（失敗した実行には印が付きます）、どれでも開けます。**編集** はカードの **…** メニューに移りました。

片付けも速くなりました：セッションのメニュー（右クリック、モバイルでは長押しでも可）から **選択** を選び、好きなだけセッションにチェックを入れて、まとめて削除できます。

詳しくは [スケジュールタスク](./guides/schedule.md) と [セッション](./guides/sessions.md) を参照してください。

### プロンプトキャッシュのヒット率を大幅改善 {#2026-10-19-cache-hits}

長い会話でプロンプトキャッシュがヒットしなかった、2 つの設計上の欠陥を修正しました：

- **履歴は追記のみに。** 会話が 10 メッセージを超えると、以前のターンのツール呼び出し・結果・推論が取り除かれ、プロンプトの先頭が書き換わっていました。今後はそれらが残るため、エージェントは以前に読んだファイルや実行したコマンドを把握したまま、作業をやり直さずに済みます。
- **メモリがキャッシュを壊さないように。** メモリの概要はプロンプト内で会話履歴より前にあり、毎ターン書き換えられていました。メモリは引き続きすぐに保存されますが、概要の更新はキャッシュが冷えたタイミングに行い、30 分以上遅れた場合は強制的に更新します。

その結果、キャッシュヒット率が大きく向上しました。

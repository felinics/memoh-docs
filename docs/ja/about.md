# Memoh について

Memoh v0.13 はオープンソースのマルチエージェントプラットフォームです。1 台のマシンで複数の AI エージェントを動かし、それぞれのエージェントが自分専用のワークスペース、ブラウザ、ネットワーク、ツール、長期メモリを持ちます。

エージェントは Telegram、Discord、Slack、Feishu、WeChat、DingTalk などのチャネル、そして Memoh アプリ内で直接会話できます。コンテキストを記憶し、ブラウザやデスクトップを操作し、MCP ツールを呼び出し、スキルやコネクターをインストールし、スケジュールタスクを実行し、Bot ごとのアクセスルールを適用できます。

自分でデプロイを運用せず、マネージドな選択肢を使いたい場合は [Memoh Cloud](https://app.memoh.net) が同じプロダクトをホスティングサービスとして提供しています。

## 提供形態

### Desktop

Desktop は Memoh Cloud またはセルフホストサーバーに接続するネイティブクライアントです。同じクライアント画面をネイティブウィンドウ・システムトレイ・ショートカット付きで包み、動かしているコンピューターを Bot が使える「コンピューター」として登録することもできます。ローカルにサーバーは立てません。

### Server Deploy

Server Deploy は常時稼働・共有利用向けです。複数ユーザーで使う、自分の PC がオフラインの間もチャネルをつなぎ続ける、セルフホストサービスとして運用する——そんな場面で選びます。Docker Compose スタックにはバックエンド、ウェブクライアント、データベース、メモリサービス、ワークスペースランタイムが含まれます。

## v0.13 の重点

### エージェントワークスペース

各 Bot は隔離されたコンテナワークスペースを使えます。ファイル、コマンド実行、MCP ホスティング、ネットワークアクセス、ヘッド付きブラウザ、グラフィカルデスクトップまで揃っています。ローカル／デスクトップ構成では、ホストレベルのアクセスを意図する場合に信頼済みローカルワークスペースも選べます。

### クライアント

クライアントは日常のプロダクト面をさらに広くカバーするようになりました：Bot のセットアップ、セッション、プロバイダー、チャネル、ワークスペースのファイル、Terminal と Desktop ペイン、マーケットプレイス、Hooks、スケジュール、アクセス制御、ユーザー環境設定。v0.13 では UI 言語として英語・簡体字中国語・日本語をサポートします。

### Hooks・スケジュール・自動化

Hooks は対応イベントの前後で小さな自動化ルールを実行し、スケジュールはチャットなしで定期的な仕事を回し続けます。マーケットプレイスのスキルとコネクターは、コードを書かずに Bot の能力を広げます。

### アクセス制御

アクセス制御はチャネル側のチャット権限とワークスペース側のユーザー権限に分かれています。Bot のオーナーはチャネルメンバーを許可・ブロックし、登録ユーザーにワークスペースロールを付与し、より精密なマッチングが必要な場合は高度な ACL ルールを使えます。

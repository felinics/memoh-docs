# ワークスペース

すべての Bot には、それぞれ自分の**ワークスペース**があります——その Bot 専用の 1 台のコンピューターです: 本物のファイルシステム、コマンドを実行できるターミナル、プリインストール済みのツールチェーン、そして必要なら目に見えるデスクトップも開けます。あなたが Bot に渡したファイル、Bot が生み出した成果物、Bot がインストールしたツールは、すべてここに住み、セッションをまたいで保持されます。

## 何ができるか

- ファイルの保存と編集——いつでも **ファイル** タブで確認できます
- スクリプトの実行とパッケージのインストール: **Node.js** と **Python** がプリインストール済み（`pip` と `uv` は PATH 上にあります）で、インタープリターの準備に手間取る必要はありません
- バックグラウンドタスクの維持
- セッションをまたいだ状態の保持——昨日やり残した作業を、今日そのまま続けられます
- オプションで、可視デスクトップとヘッド付きブラウザの実行

## クライアントでの入口

Bot の詳細ページでは、次のタブがワークスペースに面しています:

| タブ | 内容 |
|--------|------|
| **Workspace** | ワークスペースの状態とライフサイクル: 作成、起動、停止。実行情報、スナップショット、インポート／エクスポート |
| **ファイル** | ワークスペースのファイルシステムの閲覧と編集 |
| **Terminal** | ワークスペース内で対話型シェルを開く |
| **Desktop** | 可視デスクトップ: ライブ画面、キーボードとマウスの引き継ぎ／返却 |
| **ネットワーク** | ワークスペースのネットワーク状態 |
| **アプリ** | このワークスペースにインストールされた App——スキル、依存関係、コネクター（[マーケットプレイス](./supermarket.md) を参照） |

## ライフサイクル

**Workspace** タブで管理します:

- **作成**: テンプレートから新しいワークスペースを作ります。進捗が表示されます。
- **起動 / 停止**: 使わないときは停止してリソースを節約できます。中身は失われません。
- **削除**: この実行インスタンスを削除します。

ターミナルやデスクトップなど、ほとんどの機能はワークスペースが**実行中**であることを必要とします。アプリのインストールや更新も同じです。タブには、実行状態、イメージ、バックグラウンドタスク数などの実行情報もあわせて表示されます。

## 可視デスクトップ

**Desktop** タブで、グラフィカルデスクトップの有効化と確認を行います。有効にすると、Bot はワークスペース内で**ヘッド付きブラウザ**を動かせるようになり、あなたがデスクトップパネルで見ている画面と Bot が操作している画面は同じものです:

- Bot の操作を一歩ずつリアルタイムで見られます
- いつでもキーボードとマウスを**引き継ぎ**——パスワードの入力や CAPTCHA の突破——そして制御を**返せます**
- ブラウザのセッションはワークスペースに残るので、次のタスクではログインし直す必要がありません

ツールレベルでの違いは [Browser / Computer Use](./browser-computer-use.md) を見てください。

## スナップショット

**スナップショットを作成**はワークスペースの現在の状態を記録します。大きな変更の前にロールバックポイントを残しておくのに向いています。**復元**は選んだスナップショットの状態まで巻き戻し、不要なスナップショットは削除できます。

## インポート／エクスポート

- **データのエクスポート**: ワークスペースのファイルをまとめてダウンロードします。
- **データのインポート**: アーカイブをアップロードしてワークスペースに展開します。
- **リセット**: データディレクトリをまっさらな状態に戻します——ファイルシステムが荒れてしまったとき、最初からやり直したいときに使います。

::: tip セルフホストについて
ワークスペースがどのランタイム（containerd、Docker、Apple container、信頼済みローカルディレクトリ）で動くか、GPU などのホストデバイスをどうワークスペースに渡すかは、サーバー側のデプロイ設定です。[Workspace バックエンド](../self-hosted/workspace-backends.md) を見てください。Memoh Cloud のユーザーはこれらを気にする必要はありません。
:::

# マーケットプレイス（Supermarket）

マーケットプレイスは Memoh 内蔵のアプリカタログです。ここでいう**アプリ（App）**はパッケージ化された機能の単位で、1 つの App には複数の**スキル**（再利用可能な手順の説明）、**依存関係**（ワークスペースにインストールされるツール）、そして**コネクター**（GitHub や Notion といったサードパーティサービスとの連携）を含められます。インストールするのは App 全体なので、スキルやコネクターを別々に探す必要はありません。

クライアントのサイドバーから **マーケットプレイス** を開きます。アプリはカテゴリー別に並び、検索やタグでの絞り込みができます。詳細ページでは、アプリの説明、コンポーネント構成（スキル・依存関係・コネクターの数）、作者、バージョン、提供元 Registry、リンクを確認できます。

---

## アプリをインストールする

1. **マーケットプレイス** でアプリを選び、詳細ページを開きます。
2. **Botにインストールする** をクリックし、対象の Bot を選びます。
3. アプリが環境変数を宣言している場合は、必要な値を先に入力します。
4. インストールを確定します。

インストールと更新には、その Bot のワークスペースが実行中である必要があります。スキルはワークスペースに書き込まれ、依存関係はワークスペースにインストールされ、コネクターは連携が確立されます。インストール中は進捗が表示され、中断した場合は **セットアップを続行** または **インストールを復元** で再開できます。

---

## インストール後：Bot の「アプリ」タブ

Bot 詳細ページの **アプリ** タブには、インストール済みの App がコンポーネント別のステータスとともに一覧表示されます。

| コンポーネント | 行き先 |
|------|------|
| **スキル** | ワークスペースの管理対象ディレクトリ `/data/skills/<registry>/<app>/` に書き込まれ、アプリが管理します——更新・アンインストール時に一緒に処理されるため、手動で変更しないでください（[スキル](./skills.md) を参照） |
| **依存関係** | その Bot のワークスペースにインストールされ、同じワークスペース内でそれらを必要とする他のアプリと共有されます |
| **コネクター** | **認証が必要**・**任意**・**全ワークスペースで共有** のいずれかが表示されます。**認証する** をクリックして OAuth を完了するか、API Key を入力します（[コネクター](../self-hosted/connectors.md) を参照） |

よく使う操作：**更新を確認**、**更新**、**アンインストール**。一部のコンポーネントが失敗したり未認証のままだったりすると、アプリは「要対応」と表示されます。コンポーネント一覧を開いて設定を済ませてください。

---

## カタログの提供元

マーケットプレイスのコンテンツは上流の Registry から提供され、デフォルトは `supermarket.memoh.ai` です。セルフホストのインスタンスでは `supermarket.base_url` を別の信頼できるカタログに向けられます。設定リファレンスは [Server Deploy](../self-hosted/docker.md) を参照してください。

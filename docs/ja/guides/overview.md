# Memoh の概要

Memoh はすべての Bot に、それぞれ専用のクラウドコンピューターを与えます。本物のファイルシステムとターミナルを備えたワークスペース、画面を見ながら引き継ぎもできるデスクトップブラウザ、そしてセッションをまたいで引き継がれる長期メモリです。ノート PC を閉じても、Bot はそのまま働き続けます。

Bot との協働は、メッセージを送ることから始まります。Memoh アプリで話しかけることも、Telegram、Slack、Discord、Feishu、DingTalk、WeCom、WeChat、QQ、LINE に接続することもできます。どの入り口から入っても、相手は同じ Bot、同じメモリです。

始めるのに必要なのは、アプリをダウンロードして Memoh Cloud にサインインすることだけです。ホスト済みモデル（DeepSeek、Kimi、GPT、Claude など）はそのまま使えます。自分の API Key やモデルサービスを使いたい場合は [BYOK](./quick-start.md#自分のモデルを使う-byok) を参照してください。

## Memoh は何が違うのか

- **使い捨てのサンドボックスではなく、本物のコンピューター。** 書き込んだファイルもインストールしたランタイムも [ワークスペース](./container.md) に残ります。月曜日に用意したものは、金曜日にもそのまま使えます。
- **目に見える画面。** Bot は可視デスクトップ上で本物のブラウザを操作します。ログインや CAPTCHA にぶつかったら、あなたが [キーボードとマウスを引き継いで](./browser-computer-use.md) その手順を済ませ、また Bot に操作を返せます。
- **覚えている。** [長期メモリ](./memory.md) はセッションとチャネルをまたいで働きます。一度直してもらった好みを、もう一度言い直す必要はありません。
- **あなたがいなくても動いている。** [スケジュールタスク](./schedule.md) は cron で発火し、接続済みのチャネルに結果を届けます。時間どおりにチェックし、変化があったときだけ報告します。
- **自分のコーディングエージェントを持ち込める。** [ACP](./acp.md) 経由で Claude Code や Codex を同じワークスペースに入れて、自分のサブスクリプションで使えます。

## 1 つの Bot に 1 つの仕事

どの Bot も専用のワークスペース、メモリ、チャネル、権限境界を持ち、互いの中身は見えません。仕事が本当に別々の役割に分かれるときは、1 つの Bot に積み増すのではなく、もう 1 つ Bot を作ってください。誰が Bot と話せるか、誰がファイルを読み書きできるか、誰がコマンドを実行できるかは、[アクセス制御](./access.md) でレベルごとに付与します。必要なレベルだけを与えてください。

## 最初のタスクの渡し方

毎週手作業でこなしている小さな仕事を 1 つ選び、結果・ソース・境界をはっきり伝えます。

> 毎週金曜 17:00 に、今週私が送ったリンクとファイルを週報にまとめてください。テーマごとにグループ化して、1 件につき 1 行で。ワークスペースに保存し、要約をこの会話に投稿してください。まとめるのは私が送った内容だけにして、誰にも外部へ送らないでください。

Bot は自分でスケジュールタスクを登録し、毎週届けてくれます。まずは読み取り専用の仕事から始め、成果物を何度か確認してから、書き込みや実行の権限を少しずつ広げましょう。

## よくある質問

**自分のコンピューターの電源を切っても動き続けますか？**

はい。Bot はクラウドのワークスペースで動いているため、スケジュールタスクは通常どおり発火し、チャネルのメッセージにも通常どおり返信します。

**Bot はいくつ作れますか？**

サブスクリプションプランによります。各 Bot は独立していて、専用のワークスペース・メモリ・権限を持ち、1 つ削除しても他には影響しません。

**自分のファイルはどこに置かれますか？**

その Bot の隔離されたコンテナワークスペース（`/data`）にあります。セッションをまたいで保持され、[ファイル](./files.md) からいつでも閲覧・編集できます。

**自分のモデルを使えますか？**

使えます。モデルプロバイダーに自分の API Key を追加してください（[BYOK](./quick-start.md#自分のモデルを使う-byok) を参照）。コーディングエージェントは、Bot の **エージェント** タブで自分の Claude Code / Codex サブスクリプションにサインインします。

**サブスクリプションや課金の質問はどこで聞けますか？**

[ヘルプセンター](https://memoh.ai/help) へ。プラン、credits、アカウントの質問に加えて、Memoh チームへの連絡窓口もあります。

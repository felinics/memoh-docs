# ファイル

どの Bot も専用の **ワークスペースファイルシステム** を持っています。サーバーデプロイでは通常コンテナ型ワークスペースの中にあり、信頼済みのデスクトップ／ローカルモードではローカルのワークスペースディレクトリになることもあります。**ファイル** タブから直接管理できます。

---

## できること

ツールバー、ディレクトリツリー、エディターを備えた **FileManager** の主な機能です。

### ブラウズ

- パンくずリストで上下の階層を移動
- **Refresh** で Bot が書いたばかりのファイルを確認
- **New Folder** でディレクトリを作成

### ファイル管理

- **Upload** でローカルのファイルをワークスペースへ
- **Rename** / **Delete**（ディレクトリは再帰的に削除可能）
- **Download** でワークスペースからローカルへ取り出し

---

## 閲覧と編集

**FileViewer** では：

- テキスト系（`.md`、`.js`、`.py`、`.toml` など）は **Monaco** で開きます。シンタックスハイライト付きで、保存するとディスクに書き戻されます。
- 画像（`.png` など）はプレビューできます。

---

## Bot との関係

Bot 自身もスキルや MCP などを使ってこれらのファイルを変更できます。**ファイル** タブは、あなたがワークスペースを**自分の目で確かめ、手で直す**ための入り口です。

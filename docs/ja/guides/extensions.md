# 拡張機能の選び方

Memoh には、Bot に能力を足す方法が 5 つあります。名前だけ見ると紛らわしいものの、並べてみればはっきりします——なので、そのまま並べました。

| 拡張方式 | それは何か | どこにあるか／どう発火するか | 向いている用途 |
|----------|----------|-------------------|----------|
| [スキル](./skills.md) | Bot の仕事のやり方を変える `SKILL.md` プロンプトモジュール | Bot ワークスペースの `/data/skills/` 配下。**スキル** タブで管理し、会話の中で呼び出す | 本来なら毎回打ち直すことになる手順や仕事の進め方 |
| [Hooks](./hooks.md) | `hooks.json` に書く、コマンドやツールを実行できるイベントルール | `/data/.memoh/hooks.json` にあり、**Hooks** タブで編集。`PreToolUse` や `TurnEnd` のようなライフサイクルイベントで発火 | 決まったポイントでのチェックや付随アクション。チャットを一切経由しない |
| [MCP](./mcp.md) | 外部の MCP ツールサーバーへの接続 | Bot ごとに **MCP** タブで設定し、Stdio または Remote で接続。発見されたツールは会話の中で使う | MCP server を自前で備えているツールをつなぐ |
| [コネクター](../self-hosted/connectors.md) | GitHub や Notion のようなサービスへの OAuth / API Key の紐付け | アプリのコンポーネントとして App と一緒にインストールされ、Bot の **アプリ** タブで認証・管理。サービスのツールが会話に現れる | ホスティングされたサービス上の自分のアカウントで Bot に作業させる |
| [マーケットプレイス](./supermarket.md) | Memoh 内蔵のカタログ。パッケージ化されたアプリ——スキルとその依存関係・コネクター——をワンクリックでインストール | サイドバーから開く。インストールした内容は対象 Bot のワークスペースと **アプリ** タブに入る | 部品を自分で組み立てずに、出来合いの能力をそのまま手に入れる |

能力がどの経路から入ってきても、最終的には同じ場所に合流します。コネクターと MCP のツールは会話の中でワークスペースツールと並んで現れ、インストールされたスキルは手書きのものと何も変わらない形で Bot の **スキル** タブに現れます。

## どれを使うべきか

- Bot の仕事のやり方を変えたい → [スキル](./skills.md)。
- 決まったイベントの時点で自動的に何かをしたい → [Hooks](./hooks.md)。
- MCP server を持つツールをつなぎたい → [MCP](./mcp.md)。
- Bot に自分の GitHub/Notion アカウントを使わせたい → [コネクター](../self-hosted/connectors.md)。
- 出来合いの一式をワンクリックで入れたい → [マーケットプレイス](./supermarket.md)。

::: tip 重ねて使えます
この 5 つは排他的な選択肢ではありません。マーケットプレイスでインストールした 1 つのアプリがスキルとコネクターを同時に連れてくることもありますし、MCP 経由で入ってきたツールを Hook で見張ることもできます。Bot ごとに 1 種類だけ選ぶのではなく、上の問いに沿って選んでください。
:::

## どこから始めるか

どの方法にも 1 ページまるごとの解説があり、この表が圧縮してしまった詳細を展開しています:

- [スキル](./skills.md)——`SKILL.md` の書き方、スキルの状態、発見されたスキルの取り込み。
- [Hooks](./hooks.md)——イベントカタログ、設定の構造、ルールのテスト方法。
- [MCP](./mcp.md)——Stdio と Remote の接続、OAuth、ツールの発見。
- [コネクター](../self-hosted/connectors.md)——接続状態、再認証、ツールの名前空間。
- [マーケットプレイス](./supermarket.md)——カタログの閲覧、Bot へのインストール。

迷ったら、まずマーケットプレイスを覗いてみてください——出来合いのパッケージを 1 つインストールして、完成形がどんな姿なのかを先に見てから、自分のものを組み立てましょう。

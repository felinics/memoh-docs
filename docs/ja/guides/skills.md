# スキル

**スキル（Skill）**は再利用可能なプロンプトモジュールで、口調・手順・ツールの使い方といった決まったやり方を Bot に教えるためのものです。スキルに専用の管理画面はありません——ワークスペース内のファイルそのものであり、正しいディレクトリに置くだけで読み込まれます。

::: tip 制限
1 つのセッションで同時にリクエストできるスキルは最大 5 件です。注入されるサイズは 1 スキルあたり最大 64 KiB、合計で最大 256 KiB です。これらの上限は変更できません。
:::

## スキルの形

スキルは 1 つのディレクトリで、その中に YAML ヘッダー付きの `SKILL.md` を置きます。最低限、安定した `name` と短い `description` が必要です。本文が、実際に Agent へ注入される説明になります。

```yaml
---
name: coder-skill
description: Enables advanced coding workflows and tool usage.
---

# Coder Skill

コードは明快に書き、トレードオフを説明し、必要なときはファイル／コマンドツールを使ってください。
```

名前はシンプルな ASCII にし（例: `coder-skill`、`research`）、スペースは入れないでください——名前はそのままディレクトリ名にもなります。

## どのディレクトリに置くか

自分で書いたスキルは、Bot のワークスペースの次のディレクトリに置きます。

```text
/data/skills/user/personal/<スキル名>/SKILL.md
```

置き方は自由です。Bot の **ファイル** タブで直接ディレクトリとファイルを作成しても、**Terminal** で操作しても、あるいは Bot 自身に作らせても構いません——ワークスペースには `skill-creator` スキルが最初から入っているので、ほしい手順をきちんと説明すれば、正しい場所にファイルを書いてくれます。

ほかのディレクトリも目にしますが、**手動でファイルを置いてはいけません**。

| ディレクトリ | 所有者 |
|------|--------|
| `/data/skills/user/personal/` | **あなた**。手書きのスキルはすべてここに置きます |
| `/data/skills/<registry>/<app>/` | [アプリ](./supermarket.md)。App のインストール・更新・アンインストールと一緒に処理されるため、手で変更しないでください |
| `/data/.memoh/skills/` | ワークスペーステンプレートの内蔵スキル（`skill-creator` など）。ワークスペースを初期化するたびにテンプレート版へ戻されるため、編集しても上書きされます。カスタマイズしたい場合は別の名前で自分のディレクトリへコピーしてください |
| `/data/.skills/`、`/data/.agents/skills/` | 旧版向けの互換パス。検出専用で、新規追加はしないでください |

## 同名のスキルがある場合

**スキル名がそのまま識別子です**。同名のスキルがいくつのディレクトリにあっても、同時に有効になるのは 1 つだけです。自分のディレクトリにある同名スキルは、旧版互換パスにあるものより優先されます。ある App のスキルの挙動を変えたいときは、そのファイルを編集するのではなく、新しい名前で自分のバージョンを書いてください。

## おすすめ

1. まずは少数精鋭にし、`name` と `description` を明確に書きます——Agent は説明を見て、そのスキルを読み込むかどうかを決めます。
2. 繰り返し登場する手順だけをスキルとして固定する価値があります。一回限りの要望はその場で伝えれば十分です。
3. 再利用できるものは[マーケットプレイス](./supermarket.md)からインストールし、コピーの複製を増やさないようにします。

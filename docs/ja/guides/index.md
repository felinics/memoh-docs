# リファレンス

Memoh リファレンスへようこそ。Memoh のインストール・設定・活用に必要な情報はすべてここにあり、3 つのセクションで構成されています。

## はじめに

Memoh が初めてなら、ここから始めましょう。アプリのインストール、最初の Bot の作成、チャネルへの接続、そして日常的な基本操作を学べます。

- **[概要](./overview.md)**：Memoh とは何か、各パーツがどう組み合わさっているか。
- **[クイックスタート](./quick-start.md)**：アプリをインストールしてサインインし、最初の Bot を作成して実際の仕事を任せ、チャットプラットフォームに接続します。
- **[Bot との協働](./working-with-bots.md)**：どんなタスクを任せるか、依頼をどう伝えるか、いつ Bot を分けるか。さらにタブごとの設定リファレンスも。
- **[セッション](./sessions.md)**：chat と discuss、ルーティング、ステータスパネルを理解します。
- **[ファイル](./files.md)**：Bot のワークスペースにあるファイルを閲覧・編集します。
- **[スラッシュコマンド](./slash-commands.md)**：コマンドで日常の操作を手早く済ませます。
- **[チャネル](../integrations/channels/index.md)**：Memoh を Slack、Telegram、Feishu、Discord などのプラットフォームに接続します。

## 高度な機能

基礎が固まったら、さらに深く使いこなしましょう。これらのページでは、高度な機能、自動化、外部プロバイダーを扱います。

- **[拡張機能の選び方](./extensions.md)**：スキル、Hooks、MCP、コネクター、マーケットプレイスのどれを使うべきか。
- **[Agents / ACP](./acp.md)**：マルチエージェントワークフローを構築し、Agent Client Protocol と連携します。
- **[承認と信頼](./approvals.md)**：Bot が何に触れられるか、いつあなたに確認するか、どの操作を承認の後ろに残すか。
- **[アクセス制御](./access.md)**：ACL プリセット、アクセスモード、スコープ付きルールを設定します。
- **[ワークスペース](./container.md)**：プロダクト UI からワークスペースの挙動を理解します。
- **[Browser / Computer Use](./browser-computer-use.md)**：ヘッド付きブラウザと可視デスクトップのセッションを使います。
- **[スキル](./skills.md)** と **[マーケットプレイス](./supermarket.md)**：再利用できるプロンプトモジュールやテンプレートを追加します。
- **[コネクター](../self-hosted/connectors.md)**：GitHub や Notion などのサードパーティサービスに接続します。
- **[Hooks](./hooks.md)** と **[MCP](./mcp.md)**：ツール、自動化ルール、外部データソースをつなぎます。
- **[長期メモリ](./memory.md)**：メモリプロバイダーを設定したうえで長期メモリを管理します。
- **[コンテキスト圧縮](./compaction.md)**：現在のセッションのコンテキスト使用量を減らします。
- **[スケジュールタスク](./schedule.md)**：cron スケジュールで定期的な仕事を実行します。
- **[モデルプロバイダー](../integrations/providers/llm.md)**：モデルプロバイダーとモデル。ウェブ検索・動画・メモリ・TTS の各プロバイダーはサイドバーの同じ階層にあります。

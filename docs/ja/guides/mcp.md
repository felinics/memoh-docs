# MCP 接続

Memoh は **Model Context Protocol (MCP)** をサポートしており、Bot を外部ツールやコンテキストサービスに接続できます。各 Bot は自分専用の MCP 接続のセットを持てます。

## 何をするものか

MCP は「外部データ・外部ツール」を比較的統一された方法で取り込みます。Bot の **MCP** タブで手動設定するか、[マーケットプレイス](./supermarket.md) からテンプレートをインストールしてエディターで調整します。

---

## 接続タイプ

### 1. Stdio（ローカルプロセス）

Bot の**コンテナ内**でローカルコマンドを起動し、標準入出力で通信します。

| フィールド | 説明 |
|------|------|
| **Command** | 実行ファイル。例: `npx`、`python3` |
| **Arguments** | 引数のリスト |
| **Env** | 環境変数 |
| **CWD** | 作業ディレクトリ |

### 2. Remote（HTTP/SSE）

ネットワーク経由のリモート MCP です。

| フィールド | 説明 |
|------|------|
| **URL** | サーバーのエンドポイント |
| **Headers** | 認証ヘッダーなど |
| **Transport** | `http` または `sse` |

---

## OAuth

OAuth が必要な MCP サーバーもあります。Memoh は MCP の OAuth フローを完全にサポートしています。

1. 認証が必要な接続で **OAuth** をクリックします。
2. サーバー側の OAuth 設定を自動で **discover** します。
3. **Authorize** で認可ページを開きます。
4. ユーザーが同意するとリダイレクトで戻り、Memoh が **token を交換**して安全に保存します。

状態の確認や、**Revoke** による token の削除もできます。

---

## 操作

- **Add Connection**：接続を 1 件追加します。タイプを選んでフォームに入力します。
- **Import JSON**：標準の `mcpServers` JSON から複数の接続を一括インポートします。
- **Export**：バックアップや共有のためにエクスポートします。
- **Toggle Active**：削除せずに、個別の接続をオン／オフします。
- **Search**：名前または id で探します。
- **Batch Delete**：複数選択して削除します。

---

## ツール検出

接続が active になると、Memoh はそのサーバーが公開するツールを取得します。接続を開くと **Tools** の一覧を確認できます。必要に応じて **Probe** で手動更新します。

---

## Bot との連携

接続が確立すると、会話の中でモデルが説明に従ってこれらのツールを選んで使います。検出されたツールは推論フローに組み込まれます。具体的なツール名やパラメーターはサーバー側の定義に従います。

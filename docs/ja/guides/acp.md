# Agents / ACP

Memoh は Bot を ACP 互換のコーディングエージェントに接続できます。ACP エージェントは外部のコーディングワークフローで、Bot のチャットワークスペースから作業しつつ、自分のセッションを通常の chat / discuss とは分けて保ちます。

組み込みの agent profile は **Codex** と **Claude Code** の 2 つです。これらは現時点でサポートされているセットアップ経路であって、今後接続できる ACP 互換エージェントがこれだけに限られるという意味ではありません。

ACP エージェントは Bot のコンテナワークスペース内で動くため、Bot はコンテナベースの Workspace バックエンドを使っている必要があります。

---

## セットアップの流れ

1. Bot の**詳細ページ**を開き、**エージェント** タブに移動します。
2. エージェントごとに 1 行が表示されます。右側のスイッチで有効化し、行をクリックすると設定が開きます。
3. setup モードを選び、求められるフィールドを入力します。
4. 保存して、チャットのワークスペースから起動します。

各行は 3 つの状態のいずれかを示します: **Needs setup**（有効化済みだが認証情報が不足）、**Disabled**、緑のドット（準備完了）。

### エージェントごとの Setup モード

| エージェント | API Key | OAuth | Self-managed |
|--------|---------|-------|--------------|
| **Codex** | ✅ | ✅ ChatGPT ログイン（デバイスコード） | ✅ |
| **Claude Code** | ✅ | ✅ `claude setup-token` で生成した token を貼り付け | ✅ |

**Self-managed** は、あなたがワークスペース内で自分で管理している設定をそのまま使って、Memoh がエージェントを起動することを意味します。

### Codex のデバイスコード認証

Codex の設定で **Use Device Code** をクリックすると、Memoh が検証用 URL とワンタイムコードを表示します。OpenAI のページであなたが承認すれば、認証は自動で完了します。

> ワンタイムコードは、表示された OpenAI の検証用 URL でだけ入力してください——デバイスコードはフィッシングに悪用されることがあります。

## Adapter の自動更新

Codex と Claude Code の adapter は npm パッケージです。Memoh はサービスプロセスの起動後に（Bot ごとに）1 回だけ npm 上の最新バージョンを解決してそれを起動するため、adapter の修正は Memoh 自体をアップグレードしなくても手に入ります。解決や起動に失敗した場合は、次のサービス再起動まで、ワークスペースイメージに同梱されたバージョンにフォールバックします。

## Reasoning Effort

エージェントが対応している場合、コンポーザーのモデルピッカーで **Reasoning** にホバーすると、セッションごとに推論の強さを選べます。

- 選択肢（とその名前）は外部エージェント自身が宣言するもので、モデルを切り替えると変わることがあります。
- 未選択時のデフォルトは、Codex が `medium`、Claude Code が `high` です。
- 選択はセッションごとに独立していて、モデルの選択とは互いに影響しません。

以前選んだ強さが使えなくなった場合、Memoh は黙って失敗する代わりに、エージェントの選択肢を更新してあなたに選び直してもらいます。

## 添付ファイル

ACP エージェントのセッションはメッセージの添付ファイルをサポートします:

- **画像**: エージェントが画像入力のサポートを宣言していればネイティブに送信されます。非対応の場合でも、画像に参照できるワークスペースパスがあれば、自動的にファイル参照へフォールバックします。
- **ファイル**、長いテキストの貼り付け、引用／返信メッセージが運ぶ添付ファイルは、ワークスペースパスまたは公開 URL の形でエージェントに渡されます。
- テキストなしで添付ファイルだけを送ることもできます。

添付ファイルをエージェントに届けられないときは、黙って破棄するのではなく、チャット内で明確なエラーを報告します。

---

## デフォルトエージェント

Bot のインタラクション設定には **デフォルトエージェント** のドロップダウンがあります——Memoh 本体か、有効化済みで設定が完了している任意の ACP エージェントを選べます。影響するのはこれ以降に新しく作られる 1 対 1 のセッションだけで、既存のセッションとグループチャットの Discuss には影響しません。

---

## ACP エージェントセッション

ACP の作業には `acp_agent` セッションタイプが使われます。これらのセッションは Agents/ACP ワークフローが作成・管理するもので、通常の `/new chat` / `/new discuss` のルーティングは通りません。クライアントでは `acp_agent` で絞り込むことで、コーディング作業を日常の会話と分けて見られます。

# ウェブ検索プロバイダー

Bot に **Search Provider** を接続すると、検索エンジンの API をツールとして使い、会話の中で**リアルタイム**にウェブを検索できるようになります。

## 何をするものか

各 Search Provider は、特定の検索 API（Brave、Google など）への接続です。設定して Bot に割り当てると、新しい事実が必要なときにモデルが呼び出します。

---

## サポートされる検索エンジン

サイドバーの **ウェブ検索** ページで検索エンジンを設定します。サポートされるエンジンは次のとおりです。

| エンジン | 説明 |
|------|------|
| **Brave** | プライバシーと速度の面でよく挙げられる |
| **Bing** | カバレッジが広い |
| **Google** | 定番のウェブ検索 |
| **Tavily** | AI リサーチ向け |
| **SearxNG** | セルフホストのメタ検索 |
| **DuckDuckGo** | プライバシー重視 |
| その他 | Sogou、Serper、Jina、Exa、Bocha、Yandex など |

---

## 作成する

1. サイドバーの **ウェブ検索** を開きます。
2. **Add Search Provider** をクリックします。
3. **Name** と **API Key** を入力します。エンジンによっては **base_url** も必要です（SearxNG など）。

変更は **Edit**、削除は **Delete** で行います。

---

## Bot に割り当てる

1. **Bots** → Bot
2. **一般**
3. **Search Provider** のドロップダウンで選択
4. 保存

---

## Bot での使われ方

**比較的新しく、質問に即した**公開情報が必要なときに検索が実行され、結果が回答に織り込まれます。複数の検索結果をまとめることもあります。具体的な戦略は、モデルとツールの設計によって決まります。

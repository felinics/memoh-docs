# Feishu (Lark)

Feishu オープンプラットフォーム経由で接続し、企業の Bot がグループチャットとプライベートチャットでユーザーとやり取りできるようにします。

## 前提条件

- [Feishu オープンプラットフォーム](https://open.feishu.cn/app) にログインでき、カスタムアプリを作成できるアカウント。
- Memoh Bot。チャネルはその **プラットフォーム** タブで設定します。

## 手順

### 1. Feishu オープンプラットフォームでカスタムアプリを作成する

1. [Feishu オープンプラットフォーム](https://open.feishu.cn/app) を開いてログインします。
2. **カスタムアプリを作成** をクリックし、名前と説明を入力して作成します。
3. 左側のメニューから **認証情報と基本情報** に移動します。
4. **App ID** と **App Secret** をコピーします。

### 2. Feishu オープンプラットフォームで Bot 機能を有効にする

**アプリ機能** → **Bot** に移動し、有効化します。

### 3. Feishu オープンプラットフォームで権限を設定する

1. **アプリ機能** → **権限管理** に移動します。
2. 少なくとも次を有効にします。
   - `im:message`（メッセージの送受信）
   - `im:chat`（グループ情報など）
3. 組織で必要とされる場合は、**権限を申請** をクリックして提出します。

### 4. Memoh で Feishu チャネルを追加する（デフォルト：長期接続）

1. Bot の **プラットフォーム** タブを開き、**Feishu** チャネルを追加します。
2. **受信方式** はデフォルトの `websocket` のままにします。
3. **App ID** と **App Secret** を入力します。国際版 Lark を使う場合は **リージョン** を `lark` に切り替えます。
4. **Save** をクリックします。メッセージは Feishu の **WebSocket 長期接続** 経由で届くため、公開のコールバック URL は不要で、イベントサブスクリプションの設定も要りません。

### 5. オプション：Webhook 受信に切り替える

サーバーがインターネットから到達可能で、イベントコールバック方式を使いたい場合にのみ選択してください。

::: tip
このステップでは Memoh と Feishu コンソールを行き来します。Memoh が生成したコールバック URL を **イベントサブスクリプション** ページに貼り付けるので、Feishu コンソールはまだ閉じないでください。
:::

1. Memoh で **受信方式** を `webhook` に変更します。**App ID**、**App Secret** に加えて、Feishu コンソールのイベントサブスクリプション設定と一致する **Encrypt Key** と **Verification Token** も入力します。
2. **Save** をクリックすると、画面に **Webhook コールバック URL** が生成されるので、コピーします。
3. Feishu コンソールに戻り、**アプリ設定** → **イベントサブスクリプション** を開き、URL を **リクエスト URL** に貼り付けて保存します。
4. **メッセージ受信**（`im.message.receive_v1`）などのイベントを追加します。

> 公式ガイド：[Feishu カスタム Bot](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)

### 6. Feishu オープンプラットフォームでアプリをリリースする

1. **アプリリリース** → **バージョン管理とリリース** に移動します。
2. **バージョンを作成** をクリックし、情報を記入して承認を申請します。
3. 承認されて公開されると、テナント内で Bot が利用できるようになります。

## 認証情報

| フィールド | 説明 |
|------|------|
| **App ID** | Feishu オープンプラットフォームの **認証情報と基本情報** ページで取得します。 |
| **App Secret** | App ID と同じページで取得します。 |
| **リージョン** | 国際版 Lark を使う場合は `lark` に切り替えます。 |
| **受信方式** | `websocket`（デフォルト、長期接続）または `webhook`。 |
| **Encrypt Key** | webhook モードでのみ必要。Feishu コンソールのイベントサブスクリプション設定と一致させる必要があります。 |
| **Verification Token** | webhook モードでのみ必要。Feishu コンソールのイベントサブスクリプション設定と一致させる必要があります。 |

## 動作確認

Feishu で Bot とのプライベートチャットを開き、`/help` を送信します。Bot がコマンド一覧を返せば、チャネルは機能しています。

## グループチャット

Feishu はグループチャットに対応しています。Bot をグループに追加して @メンションすると、グループ内で会話できます。

## 無効化と認証情報の更新

Bot の **プラットフォーム** タブから、いつでもこのチャネルを無効化・削除できます。認証情報を更新するときは、該当するフィールド（**App Secret** など）を更新して保存してください。

## よくある質問 {#faq}

### チャネルを設定したのに Bot が反応しない {#app-not-published}

カスタムアプリはまずリリースが必要です。Feishu オープンプラットフォームの **アプリリリース** → **バージョン管理とリリース** でバージョンを作成して承認を申請します。承認されて公開されると、テナント内で Bot が利用できるようになります。

### 権限に承認が必要 {#permission-approval}

組織によってはアプリ権限に承認フローがあります。**アプリ機能** → **権限管理** で **権限を申請** をクリックして提出してください。

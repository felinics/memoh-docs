# QQ

QQ オープンプラットフォームの公式 Bot を通じて Memoh を QQ につなぎます。プライベートチャット、グループチャット、話題（スレッド）での会話に対応します。

::: warning 使用制限
- 1 つの QQ アカウントで作成できる Bot は最大 5 個です。
- 返信は完全なメッセージブロック単位で届き、token ごとのストリーミング出力は行われません。
:::

## 前提条件

- QQ アカウント。[QQ Bot オープンプラットフォーム](https://q.qq.com/qqbot/openclaw/) へのログインに使います。

## 手順

### 1. QQ オープンプラットフォームで Bot を作成する

QQ Bot オープンプラットフォームで次を行います。

1. [QQ Bot オープンプラットフォーム](https://q.qq.com/qqbot/openclaw/) を開き、QQ アカウントでログインします。
2. **创建机器人**（Create Bot）をクリックします。審査は不要です。
3. ページに表示される **AppID** と **AppSecret** をコピーします。**AppSecret** は一度しか表示されないので、必ず安全に保管してください。

> 公式リソース：[QQ Bot オープンプラットフォーム](https://q.qq.com/) · [QQ Bot ドキュメント](https://bot.q.qq.com/wiki/)

### 2. Memoh でチャネルを追加する

Memoh で次を行います。

1. Bot の **プラットフォーム** タブを開きます。
2. **Add Channel** をクリックし、**QQ** を選択します。
3. **AppID** と **AppSecret** を貼り付けます。
4. 必要に応じてオプション設定を調整します。**Markdown Support** と **Enable Input Hint** はどちらもデフォルトで有効です。
5. **Save and Enable** をクリックします。

## 認証情報

| フィールド | 必須 | 説明 |
|------|------|------|
| **AppID** | はい | Bot の App ID。Bot 作成時に QQ オープンプラットフォームのページに表示されます。 |
| **AppSecret** | はい | Bot の App Secret。作成時に一度だけ表示されます。 |
| **Markdown Support** | いいえ | Markdown 形式を有効にします（デフォルト：有効）。 |
| **Enable Input Hint** | いいえ | 返信の生成中に「入力中」の表示を出します（デフォルト：有効）。 |

## 動作確認

プライベートチャットで Bot に `/help` を送るか、グループチャットで Bot を @メンションして `/help` を送ります。Bot がコマンド一覧を返せば、チャネルは接続できています。

## グループチャット

Bot は QQ のグループチャットと話題（スレッド）での会話に対応しています。グループ内で Bot を @メンションすると返信します。

## 無効化と認証情報の更新

Bot の **プラットフォーム** タブから、いつでもこのチャネルを無効化・削除できます。認証情報を更新するときは、同じパネルで **AppID** / **AppSecret** を更新して保存してください。

## よくある質問 {#faq}

### AppSecret が分からなくなった {#appsecret-reset}

**AppSecret** は Bot 作成時に一度しか表示されません。QQ オープンプラットフォームで再度表示しようとすると強制的にリセットされます。リセット後は、Memoh で **AppSecret** を更新して保存してください。

# DingTalk

Memoh Bot を DingTalk につなぎ、組織内のプライベートチャットとグループチャットに対応させます。受信メッセージは DingTalk の Stream モード経由で届き、返信とメディアは DingTalk 公式 API 経由で送信されます。

::: warning 使用制限
- 返信は完全なメッセージ単位で届き、token ごとのストリーミング出力は行われません。
:::

## 前提条件

- 組織の DingTalk オープンプラットフォームにアクセスでき、アプリを作成する権限があること。
- 公開のコールバック URL は不要です。Memoh が DingTalk との Stream 長期接続を自動的に維持してメッセージを受信します。

## 手順

### 1. DingTalk オープンプラットフォームでアプリを作成する

組織の DingTalk オープンプラットフォームで次を行います。

1. Bot として使うアプリを作成するか、既存のアプリを選びます。
2. そのアプリの Bot／メッセージ機能を有効にします。
3. **App Key** と **App Secret** をコピーします。
4. アプリにメッセージ権限を付与し、利用者がアクセスできるように組織内で公開します。

### 2. Memoh でチャネルを追加する

Memoh で次を行います。

1. Bot の **プラットフォーム** タブを開きます。
2. **Add Channel** をクリックし、**DingTalk** を選択します。
3. **App Key** と **App Secret** を入力します。
4. **Save and Enable** をクリックします。

Memoh が DingTalk の Stream 長期接続を自動的に維持するため、webhook のコールバックアドレスを貼り付ける必要はありません。

## 認証情報

| フィールド | 必須 | 説明 |
|------|------|------|
| **App Key** | はい | DingTalk アプリの Key。DingTalk オープンプラットフォームのアプリ認証情報からコピーします。 |
| **App Secret** | はい | DingTalk アプリの Secret。App Key と同じ場所でコピーします。 |

## 動作確認

プライベートチャットで Bot に `/help` を送るか、グループチャットで Bot を @メンションして `/help` を送ります。Bot がコマンド一覧を返せば、チャネルは接続できています。

## グループチャット

Bot は DingTalk のグループチャットに対応しています。対応しているグループで Bot を @メンションすると返信します。

## 無効化と認証情報の更新

Bot の **プラットフォーム** タブから、いつでもこのチャネルを無効化・削除できます。認証情報を更新するときは、同じパネルで **App Key** / **App Secret** を更新して保存してください。

# インテグレーション

インテグレーションは Memoh を外部システムにつなぐためのものです。Bot をメッセージプラットフォームに登場させたいとき、またはモデル・メモリ・音声・検索などの上流機能を設定したいときは、ここから始めてください。

## チャネル

チャネルを使うと、Memoh クライアントの外からも Bot にアクセスできるようになります。

- **[チャネル総覧](/ja/integrations/channels/)**：対応プラットフォームと共通の設定フロー。
- **[Slack](/ja/integrations/channels/slack)**、**[Telegram](/ja/integrations/channels/telegram)**、**[Feishu](/ja/integrations/channels/feishu)**、**[Discord](/ja/integrations/channels/discord)**、**[WeChat](/ja/integrations/channels/weixin)** など。

## プロバイダー

プロバイダーは Memoh を外部の機能バックエンドにつなぎます。

- **[モデルプロバイダー](/ja/integrations/providers/llm)**：上流 API、client type、モデルロールを設定します。
- **[メモリプロバイダー](/ja/integrations/providers/memory/builtin)**：内蔵メモリ、Mem0、OpenViking から選択します。
- **[ウェブ検索プロバイダー](/ja/integrations/providers/web-search)**：検索プロバイダーへの接続を設定します。

## プロダクトガイド

インテグレーションの設定が終わったら、**[ガイド](/ja/guides/)** で Bot、セッション、メモリ操作、ツール、日常のワークフローを確認してください。

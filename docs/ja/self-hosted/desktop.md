# Desktop

Memoh Desktop は、Memoh Cloud またはセルフホストの Memoh サーバーに接続するネイティブクライアントです。同じクライアント画面を Electron シェルに包み、ネイティブウィンドウ・トレイ・メニュー・ショートカットを提供し、動かしているこのコンピューターを Bot が使える **コンピューター** として登録することもできます。

Desktop は**自分ではローカルサーバーやデータベースを動かしません**。常にいずれかの Memoh サーバーに接続します：[Memoh Cloud](https://memoh.ai) か、自分の [Server Deploy](./docker.md) です。

## Desktop を使う場面

次のような場面に向いています：

- ブラウザのタブではなく、ネイティブなアプリウィンドウとシステムトレイがほしい
- 日々の Memoh ワークフローをネイティブメニューとショートカットでこなしたい
- サーバー側の Bot にこの PC のファイル・シェル・ブラウザを使わせたいが、別の runtime プロセスは動かしたくない

たまにブラウザから覗くだけなら、ウェブクライアントで十分です。

## インストール

1. [Memoh Desktop ダウンロードページ](https://memoh.ai/desktop)から、お使いのプラットフォーム向けインストーラー（macOS DMG、Windows NSIS、Linux AppImage/deb/rpm）をダウンロードします。
2. Memoh を開きます。
3. 接続画面でサーバーアドレスを入力します（または Memoh Cloud を選択）。
4. Memoh アカウントでサインインします。

## サーバーへの接続

接続画面でサーバーアドレスを入力して接続します：

- 素のドメイン（例 `memoh.example.com`）は `https://` として扱われます（localhost 系アドレスのみ既定で `http://`）。
- `/api` サフィックスがなければ自動で補われるので、ドメインだけで十分です。
- Desktop は先にサーバーの `/ping` を確認し（タイムアウト 5 秒）、成功するとサインイン画面へ進みます。

別のサーバーに切り替えるとローカルのサインイン状態はクリアされ、再ログインが必要になります。

## この PC を Bot に共有する

Desktop は、動かしているマシンをサーバー側 Bot が使える **コンピューター** として登録できます。別の runtime プロセスは不要です：**このコンピューター** のスイッチを入れて名前を付ければ、Desktop が内蔵の Memoh runtime SDK でバックグラウンドの接続を維持します。資格情報は OS のセキュアストレージに保存されます。

権限は Bot ごとに付与し、書き込みと実行は既定で承認が必要です——詳しくは[アクセス制御](../guides/access.md)を参照してください。

## Desktop が担うもの

- アプリウィンドウ、トレイアイコン、再表示と終了の挙動
- ウェブクライアントとコマンドレジストリを共有するネイティブメニュー
- 選択したサーバーへの接続と、キャッシュされたサインイン状態
- **このコンピューター** に対応する任意の Remote Runtime 接続

それ以外のすべて（Bot、セッション、メモリ、ワークスペース、チャネル）は接続先のサーバー上にあります。ワークスペースのランタイムはサーバー側で設定します。詳しくは [Workspace バックエンド](./workspace-backends.md)を参照してください。

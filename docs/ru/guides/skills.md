# Навыки

**Навык** (Skill) — это переиспользуемый модуль промпта, который учит Bot фиксированной манере работы: тону, порядку действий, привычкам обращения с инструментами. У навыков нет отдельного экрана управления — навык представляет собой файл в рабочем пространстве, и чтобы он загрузился, достаточно положить его в правильный каталог.

::: tip Ограничения
Одна сессия может запросить одновременно не более 5 навыков; один навык внедряет до 64 КиБ, суммарно — до 256 КиБ. Эти лимиты не настраиваются.
:::

## Как выглядит навык

Навык — это каталог, в котором лежит `SKILL.md` с YAML-заголовком: как минимум стабильное `name` и короткое `description`. Тело файла — тот самый текст инструкции, который реально внедряется для агента:

```yaml
---
name: coder-skill
description: Enables advanced coding workflows and tool usage.
---

# Coder Skill

Write clear code, explain trade-offs, and use the file/command tools when the task calls for them.
```

Используйте простые ASCII-имена (`coder-skill`, `research`) без пробелов — имя одновременно служит именем каталога.

## В какой каталог класть

Навыки, которые вы пишете сами, кладите в этот каталог рабочего пространства Bot:

```text
/data/skills/user/personal/<skill-name>/SKILL.md
```

Подойдёт любой способ доставить туда файл: создайте его на вкладке **Files** у Bot, воспользуйтесь **Terminal** или просто попросите самого Bot — в рабочем пространстве уже есть навык `skill-creator`: опишите нужный порядок действий, и он запишет файлы в правильное место.

Вы встретите и другие каталоги, но **класть туда файлы вручную не нужно**:

| Каталог | Кому принадлежит |
|-----------|----------|
| `/data/skills/user/personal/` | **Вам.** Все написанные вручную навыки живут здесь |
| `/data/skills/<registry>/<app>/` | [Приложениям](./supermarket.md). Устанавливаются, обновляются и удаляются вместе с приложением — не редактируйте |
| `/data/.memoh/skills/` | Встроенные навыки из шаблона рабочего пространства (например, `skill-creator`). При каждой инициализации рабочего пространства обновляются до версии из шаблона, так что правки будут перезаписаны; для кастомизации скопируйте навык под новым именем в свой каталог |
| `/data/.skills/`, `/data/.agents/skills/` | Устаревшие пути совместимости, только для обнаружения — новые файлы не добавляйте |

## Несколько копий с одним именем

**Имя навыка — это его идентичность**: в скольких бы каталогах ни встречалось одно имя, в каждый момент действует только одна копия. Навык в вашем собственном каталоге имеет приоритет над навыком в устаревшем пути совместимости. Чтобы изменить поведение навыка из приложения, не редактируйте его файлы — напишите собственную версию под новым именем.

## Рекомендации

1. Пусть навыков будет немного, но метких, с понятными `name` и `description` — агент решает, загружать ли навык, по его описанию.
2. В навык стоит превращать только повторяющиеся порядки действий; разовые требования можно просто сказать в чате.
3. Предпочитайте установку из [Supermarket](./supermarket.md) копированию дубликатов.

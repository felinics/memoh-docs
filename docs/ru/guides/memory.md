# Управление памятью Bot

Структурированная система долговременной памяти Memoh позволяет Bot запоминать информацию между разговорами, делая взаимодействие контекстно уместным и персонализированным.

## Предварительные условия

Прежде чем пользоваться вкладкой **Memory**, убедитесь, что у Bot уже настроен **Memory Provider** (провайдер памяти).

1. Создайте провайдер одного из типов на странице [провайдеров памяти](../integrations/providers/memory/builtin.md) (встроенный, Mem0 или OpenViking).
2. Откройте вкладку **General** вашего Bot.
3. Выберите провайдер в поле **Memory Provider**.
4. Нажмите **Save**.

Без провайдера памяти у Bot не будет активной конфигурации бэкенда памяти.

---

## Идея: извлечение воспоминаний

Воспоминания сохраняются и извлекаются через назначенный провайдер памяти. В зависимости от типа провайдера извлечение может использовать встроенный граф памяти, векторы pgvector или внешний API. Когда пользователь отправляет сообщение, Memoh находит наиболее релевантные воспоминания и включает их в рабочий контекст Bot.

Эта страница — о **долговременной памяти**. Это не то же самое, что **сжатие контекста сессии**, которое уменьшает объём промпта одной сессии разговора. См. [Сжатие контекста](./compaction.md).

---

## Операции

Воспоминаниями Bot вы управляете на вкладке **Memory** страницы Bot.

### 1. Создание воспоминаний

- **New Memory**: вручную введите содержимое воспоминания в текстовое поле.
- **From Conversation**: выберите конкретные сообщения из истории разговоров Bot, чтобы извлечь их в память.

### 2. Поиск и управление

- **Search**: фильтрация воспоминаний по ID или тексту.
- **Edit**: правка существующих записей прямо в списке.
- **Delete**: удаление воспоминаний, которые больше не нужны.

## Сжатие памяти

Со временем долговременные воспоминания накапливаются и начинают дублировать друг друга. Действие **Compact** на вкладке **Memory** переписывает сам хранимый набор воспоминаний.

Эта операция — обслуживание памяти на уровне провайдера. Она полезна, когда вы хотите:

- объединить пересекающиеся воспоминания;
- убрать устаревшие или малоценные записи;
- улучшить качество извлечения, снизив шум.

Параметры:

- **Ratio** — коэффициент сжатия, например `0.8`, `0.5` или `0.3`. Чем ниже значение, тем агрессивнее сжатие.
- **Decay Days** — опционально ограничивает сжатие только более старыми воспоминаниями.

Это не то же самое, что [сжатие контекста](./compaction.md): то сжимает активный промпт одной сессии, а не переписывает хранимые воспоминания.

---

## Rebuild

Функция **Rebuild** переиндексирует все воспоминания с нуля. Это полезно, когда:

- вы сменили модель эмбеддингов у провайдера памяти;
- векторный индекс пришёл в несогласованное состояние;
- вы хотите заново обработать все воспоминания с обновлёнными настройками.

Нажмите **Rebuild** на вкладке Memory, чтобы запустить процесс. За ходом перестроения можно следить в реальном времени.

---

## Статус

Вкладка Memory показывает текущий **статус** провайдера памяти для этого Bot:

- **Connected** — бэкенд памяти доступен и работает.
- **Error** — есть проблема с конфигурацией провайдера памяти или с подключением.

По индикатору статуса удобно быстро убедиться, что система памяти работает, прежде чем разбираться с другими проблемами.

---

## Статистика использования

Вкладка Memory отображает сведения об использовании хранилища:

- **Total Memories** — число записей памяти, сохранённых для этого Bot.
- **Index Status** — актуален ли векторный индекс.

---

## Память и контекст сессии

В Memoh есть два разных понятия «сжатия»:

| Понятие | Область действия | Где запускается | Что меняет |
|--------|-------------|---------------------|-----------------|
| **Сжатие памяти** | Провайдер долговременной памяти | Вкладка Memory | Переписывает хранимые записи памяти |
| **Сжатие контекста** | Одна сессия разговора | Панель статуса сессии или `/compact` | Сводит старый контекст сессии в резюме для будущих вызовов модели |

Если нужно снизить шум при извлечении по множеству разговоров — используйте **сжатие памяти**.

Если нужно укоротить историю текущего активного разговора — используйте **сжатие контекста**.

---

## Взаимодействие с Bot

- Во время чата Bot сам ищет и извлекает воспоминания.
- Назначенный **Memory Provider** определяет бэкенд памяти, который использует Bot.
- Настройки конкретного провайдера (например, модель эмбеддингов или API-ключи) задаются на самом провайдере — см. [Провайдеры памяти](../integrations/providers/memory/builtin.md).
- Воспоминания дают те долговременные знания, которые делают каждого Bot уникальным для его владельца.

# MCP-подключения

Memoh полностью поддерживает **Model Context Protocol (MCP)** и позволяет подключать Bot к внешним сервисам инструментов и поставщикам контекста.

## Идея: расширение возможностей Bot

MCP даёт стандартизированный способ открыть Bot доступ к внешним источникам данных и инструментам. У каждого Bot может быть собственный независимый набор MCP-подключений.

Подключения можно настраивать вручную на вкладке **MCP** или начать с готового шаблона в **[Supermarket](./supermarket.md)**, а затем просмотреть предзаполненный черновик в редакторе Bot.

---

## Типы подключений

MCP-подключения настраиваются на вкладке **MCP** страницы Bot.

### 1. Stdio (локальный процесс)

Подключение этого типа выполняет локальную команду внутри контейнера Bot и общается через стандартный ввод/вывод.

| Поле | Описание |
|-------|-------------|
| **Command** | Исполняемый файл (например, `npx`, `python3`). |
| **Arguments** | Список аргументов командной строки (например, `-y`, `@modelcontextprotocol/server-filesystem`, `/opt/memoh/data`). |
| **Env** | Пары «ключ — значение» для переменных окружения. |
| **CWD** | Рабочий каталог процесса. |

### 2. Remote (HTTP/SSE)

Подключение этого типа соединяется с удалённым MCP-сервером по сети.

| Поле | Описание |
|-------|-------------|
| **URL** | Конечная точка удалённого MCP-сервера. |
| **Headers** | Пользовательские HTTP-заголовки (например, для аутентификации). |
| **Transport** | Выбор между `http` и `sse` (Server-Sent Events). |

## Аутентификация по OAuth

Некоторым MCP-серверам нужна аутентификация на основе OAuth. Memoh поддерживает полный MCP-поток OAuth:

1. Нажмите кнопку **OAuth** на подключении, требующем аутентификации.
2. Memoh автоматически **обнаружит** OAuth-конфигурацию сервера.
3. Нажмите **Authorize**, чтобы открыть страницу авторизации поставщика.
4. После выдачи доступа вы будете перенаправлены обратно в Memoh.
5. Токен **обменивается** и безопасно сохраняется для этого подключения.

Также можно:

- **Check status** — посмотреть текущее состояние OAuth-токена.
- **Revoke** — удалить сохранённый OAuth-токен.

## Операции

- **Add Connection**: нажмите **Add**, выберите тип и заполните конфигурацию.
- **Import JSON**: кнопка **Import** быстро добавляет несколько подключений из стандартного JSON-файла конфигурации `mcpServers`.
- **Export**: экспорт конфигураций подключений в JSON-файл для резервной копии или обмена.
- **Toggle Active**: включение и выключение отдельных подключений без удаления.
- **Search**: быстрый поиск подключения по имени или ID.
- **Batch Delete**: выбор нескольких подключений и удаление их разом.

## Обнаружение инструментов

Как только MCP-подключение становится активным, Memoh автоматически обнаруживает инструменты, которые предоставляет сервер. Вы можете:

1. Открыть подключение, чтобы посмотреть его детали.
2. В разделе **Tools** увидеть все доступные инструменты с их именами и описаниями.
3. Bot будет сам использовать эти инструменты в разговорах, когда это уместно.

Кнопкой **Probe** можно вручную обновить список инструментов с сервера.

---

## Взаимодействие с Bot

Когда MCP-подключение активно, Bot автоматически:
- обнаруживает инструменты и ресурсы, предоставляемые MCP-сервером;
- использует эти инструменты для выполнения задач по запросу пользователя;
- включает контекст, полученный от MCP-сервера, в процесс рассуждения.

# Слэш-команды

Bot в Memoh поддерживают **слэш-команды**, которые перехватываются до запуска LLM. Они предназначены для быстрых задач просмотра и управления: посмотреть настройки, переключить провайдера, проверить статус сессии или создать свежую сессию.

Слэш-команды работают в адаптерах каналов и во встроенном чате приложения. Сам разбор команды не расходует токены модели.

---

## Устройство команд

Большинство команд следует схеме «ресурс — действие»:

```text
/resource [action] [arguments...]
```

Примеры:

```text
/schedule list
/model current
/schedule create morning-news "0 9 * * *" "Send a daily summary"
```

Ключевые идеи:

- **resource** — группа команд, например `schedule`, `model` или `status`.
- **action** — конкретная операция, например `list`, `get`, `set` или `latest`.
- **arguments** — позиционные значения после действия. Значения с пробелами заключайте в кавычки.
- У некоторых групп есть **действие по умолчанию**: `/settings` эквивалентна `/settings get`, а `/status` — `/status show`.

Две команды являются **командами верхнего уровня**, а не группами ресурсов:

- `/new` — создать новую сессию для текущего маршрута диалога
- `/stop` — прервать текущую генерацию в текущем диалоге

## Активация навыков и быстрые действия

Помимо фиксированных команд, слэш-система может по запросу активировать [навыки](./skills.md) Bot:

```text
/<skill-name> [необязательный промпт]
```

- В **поле ввода приложения** ввод `/` открывает панель с быстрыми действиями (**Quick actions**: `/help`, `/skill list`, `/new`, `/compact`, `/model`) и навыками Bot. Выбранный навык прикрепляется как удаляемый чип; можно и напрямую набрать форму, показанную выше.
- В **IM-каналах** работает та же форма `/<skill-name>`, а `/skill list` выводит доступные навыки нажимаемыми кнопками.
- Содержимое активированного навыка подставляется **только в текущий ход** — оно не сохраняется в истории, заголовках сессий или памяти.

Имена навыков разрешаются **на сервере** по текущему действующему каталогу навыков Bot при каждой отправке. Ввод в форме слэш-команды, не совпавший ни с одной известной командой или навыком, отклоняется с понятной ошибкой, а не передаётся модели; при этом обычный текст, просто начинающийся с `/` (пути, URL), по-прежнему уходит как обычное сообщение.

Два ограничения, о которых стоит знать:

- Сообщение активации навыка не может нести вложения (фиксированные команды с вложениями выполняются как обычно).
- В групповых чатах слэш-сообщение, не адресованное Bot, молча игнорируется.

## Встроенная справка

В слэш-систему встроена многоуровневая справка:

| Команда | Значение |
|---------|---------|
| `/help` | Показать список команд верхнего уровня |
| `/help <group>` | Показать действия внутри одной группы |
| `/help <group> <action>` | Показать подробное использование одного действия |

Примеры:

```text
/help
/help model
/help model set
```

Это самый быстрый способ узнать точный действующий набор команд вашей текущей версии Memoh.

## Правила разбора

Слэш-команды поддерживают несколько удобных форм:

- **Команды с упоминанием** работают в групповых чатах, например `@BotName /help`.
- Принимаются **суффиксы Telegram-ботов**, например `/help@MemohBot`.
- Строки в кавычках сохраняются как один аргумент, например:

```text
/schedule create morning-news "0 9 * * *" "Send today's top stories"
```

Если текст не разрешается в известную команду, Memoh считает его обычным сообщением чата, а не слэш-командой.

---

## Права

Действия только для чтения доступны пользователям, которые уже могут общаться с Bot. Действия записи, такие как `set`, `create`, `update`, `delete`, `enable` и `disable`, — **только для владельца**.

В выводе `/help` действия, доступные только владельцу, помечены `[owner]`.

## Краткий справочник

### Команды верхнего уровня

| Команда | Описание |
|---------|-------------|
| `/help` | Показать справку по слэш-командам |

### Группы ресурсов

| Группа | Описание | Действие по умолчанию |
|-------|-------------|----------------|

| `/mcp` | Просмотр подключений MCP | Нет |
| `/settings` | Просмотр и изменение настроек Bot | `get` |
| `/model` | Просмотр и переключение моделей Bot | Нет |
| `/memory` | Просмотр и переключение провайдеров памяти | Нет |
| `/search` | Просмотр и переключение провайдеров поиска | Нет |
| `/usage` | Просмотр расхода токенов | `summary` |
| `/email` | Просмотр почтовых провайдеров, привязок и исходящих | Нет |
| `/skill` | Просмотр загруженных навыков Bot | `list` |
| `/fs` | Просмотр файлов в рабочем пространстве Bot | Нет |
| `/status` | Просмотр статуса сообщений/контекста/кэша сессии | `show` |
| `/access` | Просмотр контекста идентичности, роли и ACL | `show` |
| `/compact` | Немедленное сжатие контекста сессии | `run` |
| `/context` | Показ занятости контекстного окна текущей сессии | `show` |
| `/reasoning` (псевдонимы `/reason`, `/effort`, `/think`) | Просмотр или установка уровня рассуждения для этой сессии | `show` |
| `/language` | Просмотр или установка языка интерфейса команд (`auto`, `en`, `zh`, `ja`) | `show` |
| `/link <code>` | Привязка аккаунта этого канала к вашему пользователю Memoh по коду, сгенерированному в приложении | `consume` |

## Команды сессий

### `/new`

Создаёт свежую сессию для текущего маршрута диалога. Это самый быстрый способ сбросить контекст разговора без удаления старой истории.

Поддерживаемые формы:

- `/new` — использовать тип сессии по умолчанию для текущего контекста
- `/new chat` — принудительно создать обычную сессию chat
- `/new discuss` — принудительно создать сессию discuss

Поведение по умолчанию:

- **встроенный чат приложения** по умолчанию использует `chat`
- **личные сообщения** по умолчанию используют `chat`
- **групповые диалоги на адаптерах каналов** по умолчанию используют `discuss`

`/new discuss` не поддерживается во встроенном чат-канале приложения. Если нужны явные сессии discuss, используйте адаптер канала, например Telegram или Discord.

О том, чем различаются `chat` и `discuss`, см. [Сессии](./sessions.md).

### `/stop`

Останавливает текущую выполняющуюся генерацию в текущем диалоге. Это полезно, когда:

- Bot ещё выводит ответ, а вы уже получили нужное
- цикл инструментов затянулся
- вы хотите прервать текущий ход, прежде чем отправить следующее сообщение

## Команды статуса и диагностики

### `/status`

Показывает статистику текущего диалога на уровне сессии:

- число сообщений
- текущую занятость контекста
- долю попаданий в кэш
- токены чтения/записи кэша
- использованные в сессии навыки

Действия:

| Действие | Использование |
|--------|-------|
| `show` | `/status` или `/status show` |
| `latest` | `/status latest` |

Используйте `show` для активного сейчас маршрута диалога. Используйте `latest`, когда нужна самая свежая сессия Bot, даже если на текущем маршруте нет активной сессии.

### `/access`

Показывает текущую идентичность и контекст прав, которые Memoh использует для команды:

- идентичность канала
- привязанного пользователя
- роль для этого Bot
- разрешены ли команды записи
- область: канал / диалог / тред
- вычисленный результат ACL для чата

Использование:

```text
/access
```

Эта команда полезна при отладке правил ACL и выяснении, почему команда записи была отклонена.

### `/usage`

Показывает расход токенов за последние 7 дней.

Действия:

| Действие | Использование |
|--------|-------|
| `summary` | `/usage` или `/usage summary` |
| `by-model` | `/usage by-model` |


### `/email`

Показывает связанные с почтой данные конфигурации текущего Bot.

Действия:

| Действие | Использование |
|--------|-------|
| `providers` | `/email providers` |
| `bindings` | `/email bindings` |
| `outbox` | `/email outbox` |

## Команды конфигурации

### `/settings`

Показывает или изменяет основные настройки Bot.

Действия:

| Действие | Использование | Права |
|--------|-------|------------|
| `get` | `/settings` или `/settings get` | Все |
| `update` | `/settings update [options]` | Владелец |

Поддерживаемые опции `update`:

| Опция | Описание |
|--------|-------------|
| `--language` | Язык Bot, например `en` или `zh` |
| `--acl_default_effect` | `allow` или `deny` |
| `--reasoning_effort` | Уровень усилий, например `low`, `medium`, `high`, `xhigh` — допустимые значения зависят от уровней рассуждения, объявленных выбранной моделью |
| `--chat_model_id` | UUID модели чата |

Пример:

```text
/settings update --language en --reasoning_effort high
```

### `/model`

Показывает или переключает модель чата Bot.

Действия:

| Действие | Использование | Права |
|--------|-------|------------|
| `list [provider_name]` | `/model list` | Все |
| `current` | `/model current` | Все |
| `set` | `/model set <model_id>` или `/model set <provider_name> <model_name>` | Владелец |

Примеры:

```text
/model list
/model list OpenAI
/model current
/model set gpt-4o
/model set OpenAI gpt-4o
```

### `/memory`

Показывает или переключает активного провайдера памяти.

Действия:

| Действие | Использование | Права |
|--------|-------|------------|
| `list` | `/memory list` | Все |
| `current` | `/memory current` | Все |
| `set` | `/memory set <name>` | Владелец |

### `/search`

Показывает или переключает активного провайдера поиска.

Действия:

| Действие | Использование | Права |
|--------|-------|------------|
| `list` | `/search list` | Все |
| `current` | `/search current` | Все |
| `set` | `/search set <name>` | Владелец |

### `/mcp`

Показывает или удаляет подключения MCP, настроенные для Bot.

Действия:

| Действие | Использование | Права |
|--------|-------|------------|
| `list` | `/mcp list` | Все |
| `get` | `/mcp get <name>` | Все |
| `delete` | `/mcp delete <name>` | Владелец |

## Команды автоматизации и файловой системы

### `/schedule`

Управляет задачами по расписанию для Bot.

Действия:

| Действие | Использование | Права |
|--------|-------|------------|
| `list` | `/schedule list` | Все |
| `get` | `/schedule get <name>` | Все |
| `create` | `/schedule create <name> <pattern> <command>` | Владелец |
| `update` | `/schedule update <name> [--pattern P] [--command C]` | Владелец |
| `delete` | `/schedule delete <name>` | Владелец |
| `enable` | `/schedule enable <name>` | Владелец |
| `disable` | `/schedule disable <name>` | Владелец |

Примеры:

```text
/schedule list
/schedule create morning-news "0 9 * * *" "Summarize today's top tech news"
/schedule disable morning-news
```

### `/skill`

Выводит доступные сейчас навыки Bot. Показываются только навыки, **пригодные к использованию во время работы**, — отключённые или перекрытые источники опускаются.

Действия:

| Действие | Использование |
|--------|-------|
| `list` | `/skill` или `/skill list` |

Чтобы активировать навык на один ход, используйте `/<skill-name> [промпт]` — см. [Активацию навыков и быстрые действия](#активация-навыков-и-быстрые-деиствия).

### `/fs`

Просматривает файловую систему рабочего пространства Bot.

Действия:

| Действие | Использование |
|--------|-------|
| `list` | `/fs list [path]` |
| `read` | `/fs read <path>` |

Примеры:

```text
/fs list /
/fs list /home
/fs read /home/bot/IDENTITY.md
```

Вывод чтения усекается, если файл очень большой.

## Команда сжатия контекста

### `/compact`

Немедленно запускает **сжатие контекста сессии** для текущей сессии. Это не то же самое, что сжатие памяти:

- **сжатие контекста** уменьшает объём активного промпта и истории одной сессии
- **сжатие памяти** переписывает записи долговременной памяти у провайдера памяти

Действия:

| Действие | Использование |
|--------|-------|
| `run` | `/compact` или `/compact run` |

Используйте эту команду, когда текущий разговор разросся и вы хотите, чтобы Memoh резюмировал старые ходы, прежде чем продолжать. См. [Сжатие контекста](./compaction.md).

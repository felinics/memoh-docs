# Agents / ACP

Memoh может подключить Bot к ACP-совместимым агентам для программирования. ACP-агенты — это внешние рабочие процессы написания кода: они работают из чат-пространства Bot, но держат свои сессии отдельно от обычных разговоров chat и discuss.

В комплекте с Memoh идут три профиля агентов: **Codex**, **Claude Code** и **Grok Build**. Считайте их поддерживаемыми путями настройки, а не единственными возможными ACP-совместимыми агентами на будущее.

ACP-агенты выполняются внутри контейнерного рабочего пространства Bot, поэтому Bot должен использовать контейнерный бэкенд рабочего пространства.

---

## Порядок настройки

1. Откройте страницу **Detail Page** нужного Bot и перейдите на вкладку **Agents**.
2. Каждый агент показан отдельной строкой с переключателем. Щёлкните по строке, чтобы открыть его настройки.
3. Выберите режим настройки и заполните поля, которые требует этот агент.
4. Сохраните, затем запустите включённого агента из чат-пространства.

Строка показывает одно из трёх состояний: **Needs setup** (включён, но не хватает учётных данных), **Disabled** или зелёная точка (включён и готов).

### Режимы настройки по агентам

| Агент | API Key | OAuth | Self-managed |
|-------|---------|-------|--------------|
| **Codex** | ✅ | ✅ вход через ChatGPT по коду устройства | ✅ |
| **Claude Code** | ✅ | ✅ вставьте токен из `claude setup-token` | ✅ |
| **Grok Build** | ✅ API-ключ xAI | ✅ вход через аккаунт Grok по коду устройства | — |

**Self-managed** означает, что Memoh запускает агента с конфигурацией, которую вы поддерживаете сами внутри рабочего пространства.

### Авторизация Codex по коду устройства

В настройках Codex нажмите **Use Device Code**. Memoh покажет URL подтверждения и одноразовый код пользователя, а после того как вы подтвердите его на странице OpenAI, авторизация завершится автоматически.

> Вводите код только на показанном URL подтверждения OpenAI — коды устройств могут использоваться для фишинга.

### Grok Build {#grok-build}

Grok Build проходит аутентификацию по API-ключу xAI или через аккаунт Grok. При создании Bot можно указать только API-ключ; войти через аккаунт Grok можно в настройках агента, когда Bot уже создан. Memoh покажет страницу подтверждения и одноразовый код — подтверждайте его только на показанном адресе accounts.x.ai, — после чего авторизация завершится автоматически. Memoh хранит учётные данные Grok этого агента в зашифрованном виде и передаёт их Grok Build только во время выполнения.

Для своих встроенных инструментов Grok Build применяет собственный режим разрешений:

| Режим | Поведение |
|-------|-----------|
| **Ask** (по умолчанию) | Спрашивать перед каждой операцией с побочными эффектами. |
| **Auto** | Grok сам решает, какие операции безопасно выполнять без вопроса. |
| **Always approve** | Одобрять все операции без вопросов. Разрешения инструментов Memoh по-прежнему действуют. |

Правила **Tool Approval** у Bot распространяются только на инструменты, которые предоставляет Memoh. Когда Grok Build запрашивает подтверждение, Memoh показывает запрос карточкой, и решение принимает пользователь с соответствующими правами на рабочее пространство. Grok Build может ответвить разговор только от последнего хода.

## Обновления адаптеров

Адаптеры Codex и Claude Code распространяются через npm. Memoh определяет последнюю опубликованную версию адаптера один раз за запуск сервера (для каждого Bot) и запускает именно её, поэтому исправления адаптеров приходят без обновления самого Memoh. Если поиск версии или запуск не удаётся, Memoh откатывается на версию адаптера из образа рабочего пространства — до следующего перезапуска сервера. Grok Build адаптер не нужен: он изначально поддерживает ACP, и Memoh запускает CLI `grok`, который поставляется как управляемая зависимость рабочего пространства.

## Усилие рассуждения

Когда активный агент это поддерживает, вы можете выбирать усилие рассуждения для каждой сессии в селекторе моделей в поле ввода: наведите курсор на **Reasoning**, чтобы открыть список.

- Доступные варианты (и их названия) объявляет сам внешний агент; при смене модели они могут измениться.
- Значения по умолчанию, пока вы ничего не выбрали: у Codex — `medium`, у Claude Code — `high`.
- Выбор действует в рамках сессии и не зависит от выбора модели.

Если ранее выбранное усилие становится недоступным, Memoh обновляет список вариантов агента и просит выбрать заново, а не отказывает молча.

## Вложения

Сессии ACP-агентов поддерживают вложения в сообщениях:

- **Изображения** отправляются нативно, если агент объявил поддержку ввода изображений. Иначе Memoh по возможности автоматически ссылается на изображение как на файл рабочего пространства.
- **Файлы**, длинный вставленный текст и вложения из цитируемых сообщений и ответов передаются агенту как пути рабочего пространства или публичные URL.
- Можно отправить вложение вообще без текста.

Если вложение не удаётся доставить агенту, Memoh сообщает в чате понятную ошибку, а не отбрасывает его молча.

---

## Агент по умолчанию

В настройках взаимодействия Bot можно выбрать **Default Agent** (агент по умолчанию) — сам Memoh или любой включённый и полностью настроенный ACP-агент. Выбор применяется только к новым сессиям один на один; существующие сессии и групповые разговоры discuss не затрагиваются.

---

## Сессии ACP-агентов

Работа через ACP использует тип сессии `acp_agent`. Такие сессии создаются и управляются рабочим процессом Agents/ACP, а не обычной маршрутизацией `/new chat` или `/new discuss`. В приложении можно отфильтровать сессии по `acp_agent`, чтобы смотреть работу агентов для программирования отдельно от повседневных разговоров.

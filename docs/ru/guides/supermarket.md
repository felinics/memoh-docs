# Supermarket

Supermarket — это встроенный каталог приложений Memoh. **Приложение** (App) здесь — упакованная единица возможностей: одно приложение может нести несколько **навыков** (переиспользуемых порядков действий), **зависимостей** (инструментов, устанавливаемых в рабочее пространство) и **коннекторов** (привязок к сторонним сервисам вроде GitHub или Notion). Приложение устанавливается целиком — не нужно отдельно разыскивать навыки или коннекторы.

Откройте **Supermarket** в боковой панели клиента: приложения разложены по категориям, их можно искать и фильтровать по тегам. На странице приложения показаны его описание, состав компонентов (сколько навыков, зависимостей и коннекторов), автор, версия, исходный реестр и ссылки.

---

## Установка приложения

1. Выберите приложение в **Supermarket** и откройте его страницу.
2. Нажмите **Install to Bot** и выберите целевой Bot.
3. Если приложение объявляет переменные окружения, сначала заполните требуемые значения.
4. Подтвердите установку.

Для установки и обновления рабочее пространство Bot должно быть запущено: навыки записываются в рабочее пространство, зависимости устанавливаются в него, коннекторы привязываются. Установка показывает прогресс; прерванную установку можно **продолжить** или **восстановить**.

## После установки: вкладка Apps у Bot

Вкладка **Apps** на странице Bot перечисляет установленные приложения с состоянием каждого компонента:

| Компонент | Куда попадает |
|-----------|---------------|
| **Навыки** | Записываются в управляемый каталог рабочего пространства `/data/skills/<registry>/<app>/`; ими владеет приложение — они обновляются и удаляются вместе с ним, так что не редактируйте их вручную (см. [Навыки](./skills.md)) |
| **Зависимости** | Устанавливаются в рабочее пространство Bot и используются совместно с другими приложениями этого же рабочего пространства, которым они нужны |
| **Коннекторы** | Помечаются как **Needs authorization**, **Optional** или **Shared across workspaces**; нажмите **Authorize**, чтобы пройти OAuth или ввести API-ключ (см. [Коннекторы](../self-hosted/connectors.md)) |

Частые действия: **Check for updates**, **Update**, **Remove**. Если часть компонентов завершилась с ошибкой или ещё ждёт авторизации, приложение помечается как требующее внимания — откройте список его компонентов и завершите настройку.

## Откуда берётся каталог

Содержимое Supermarket отдаётся из вышестоящего реестра, по умолчанию `supermarket.memoh.ai`. В самостоятельно развёрнутых инстансах можно указать в `supermarket.base_url` другой доверенный каталог; см. справочник по конфигурации в [Server Deploy](../self-hosted/docker.md).

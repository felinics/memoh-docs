# Рабочее пространство

У каждого Bot есть собственное **рабочее пространство** — компьютер, который принадлежит ему: настоящая файловая система, терминал, выполняющий команды, предустановленный набор инструментов и, по желанию, видимый рабочий стол. Файлы, которые вы передаёте Bot, результаты, которые он производит, и инструменты, которые он устанавливает, живут здесь и сохраняются между сессиями.

## Что оно умеет

- Хранить и редактировать файлы — просматривайте их в любой момент на вкладке **Files**
- Запускать скрипты и устанавливать пакеты: **Node.js** и **Python** предустановлены (`pip` и `uv` уже в PATH), настраивать интерпретатор не нужно
- Держать фоновые задачи запущенными
- Сохранять состояние между сессиями — вчерашняя незаконченная работа продолжается сегодня
- По желанию — запускать видимый рабочий стол с браузером с графическим интерфейсом (headed)

## Где оно в клиенте

Несколько вкладок на странице Bot обращены к рабочему пространству:

| Вкладка | Содержимое |
|-----|---------|
| **Workspace** | Состояние и жизненный цикл рабочего пространства: создание, запуск, остановка; сведения о среде, снапшоты, импорт и экспорт |
| **Files** | Просмотр и редактирование файловой системы рабочего пространства |
| **Terminal** | Интерактивная оболочка внутри рабочего пространства |
| **Desktop** | Видимый рабочий стол: живая картинка, перехват и возврат клавиатуры и мыши |
| **Network** | Состояние сети рабочего пространства |
| **Apps** | Приложения, установленные в это рабочее пространство, — навыки, зависимости, коннекторы (см. [Supermarket](./supermarket.md)) |

## Жизненный цикл

Управляется с вкладки **Workspace**:

- **Create** (создание): собирает новое рабочее пространство из шаблона, с индикатором прогресса.
- **Start / Stop** (запуск / остановка): останавливайте его, чтобы не тратить ресурсы в простое, — ничего не теряется.
- **Delete** (удаление): убирает запущенный экземпляр.

Большинству возможностей — терминалу, рабочему столу, установке и обновлению приложений — нужно, чтобы рабочее пространство было **запущено**. На той же вкладке показаны сведения о среде: состояние, образ, число фоновых задач.

## Видимый рабочий стол

Вкладка **Desktop** включает графический рабочий стол и показывает его. Когда он включён, Bot может управлять **браузером с графическим интерфейсом (headed)** внутри рабочего пространства, а панель рабочего стола показывает тот же экран, которым он оперирует:

- Наблюдайте каждый шаг вживую
- **Перехватывайте** клавиатуру и мышь в любой момент — ввести пароль, пройти CAPTCHA — и **возвращайте управление**
- Сессии браузера сохраняются в рабочем пространстве, так что следующая задача уже выполняется под вашим входом

О различии на уровне инструментов см. [Browser / Computer Use](./browser-computer-use.md).

## Снапшоты

**Create Snapshot** записывает текущее состояние рабочего пространства — точка отката перед большим изменением; **Restore** возвращает к выбранному снапшоту, а ненужные снапшоты можно удалять.

## Импорт и экспорт

- **Export Data**: упаковать файлы рабочего пространства для скачивания.
- **Import Data**: загрузить архив и распаковать его в рабочее пространство.
- **Reset**: вернуть каталог данных в чистое состояние — когда файловая система разгромлена или хочется начать заново.

::: tip Самостоятельное развёртывание
На какой среде выполнения работает рабочее пространство (containerd, Docker, Apple container, доверенный локальный каталог) и как в него пробрасываются устройства хоста, например GPU, — это вопросы развёртывания на стороне сервера, см. [Бэкенды рабочих пространств](../self-hosted/workspace-backends.md). Пользователям Memoh Cloud трогать это не нужно.
:::

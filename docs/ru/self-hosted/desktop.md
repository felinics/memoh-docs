# Desktop

Memoh Desktop — нативный клиент для Memoh Cloud или самостоятельно развёрнутого сервера Memoh. Он упаковывает тот же клиентский интерфейс в оболочку Electron с нативными окнами, треем, меню и поддержкой клавиатуры, а также может зарегистрировать компьютер, на котором работает, как **Computer** (компьютер), доступный вашим Bot.

Desktop **не** запускает собственный локальный сервер или базу данных. Вы всегда подключаете его к серверу Memoh: либо к [Memoh Cloud](https://memoh.ai), либо к собственному [Server Deploy](./docker.md).

## Когда выбирать Desktop

Выбирайте Desktop, если вам нужны:

- нативное окно приложения и системный трей вместо вкладки браузера
- нативные меню и горячие клавиши для повседневной работы с Memoh
- возможность дать серверным Bot доступ к файлам, оболочке и браузеру этого компьютера без отдельного процесса рантайма

Если вам достаточно изредка заходить из браузера, пользуйтесь веб-клиентом напрямую.

## Установка

1. Скачайте установщик для своей платформы (macOS DMG, Windows NSIS или Linux AppImage/deb/rpm) со [страницы загрузки Memoh Desktop](https://memoh.ai/desktop).
2. Откройте Memoh.
3. На экране подключения введите адрес сервера (или выберите Memoh Cloud).
4. Войдите под своей учётной записью Memoh.

## Подключение к серверу

На экране подключения введите адрес сервера и подключитесь:

- «Голый» домен вроде `memoh.example.com` считается `https://` (только адреса localhost по умолчанию получают `http://`).
- Суффикс пути `/api` добавляется автоматически, если его нет, так что достаточно ввести один домен.
- Прежде чем продолжить, Desktop опрашивает эндпоинт сервера `/ping` (тайм-аут 5 секунд), а затем переводит вас к входу.

Переключение на другой сервер сбрасывает локальное состояние входа, поэтому на новом сервере придётся войти заново.

## Как поделиться этим компьютером с Bot

Desktop может зарегистрировать машину, на которой работает, как **Computer**, на котором смогут работать серверные Bot, — без отдельного процесса рантайма. Включите **This computer** (этот компьютер), дайте ему имя, и Desktop будет поддерживать соединение в фоне через встроенный Memoh runtime SDK. Учётные данные хранятся в защищённом хранилище операционной системы.

Доступ выдаётся каждому Bot отдельно, а действия записи и выполнения по умолчанию требуют подтверждения — см. [Контроль доступа](../guides/access.md).

## Чем управляет Desktop

- окном приложения, иконкой в трее, поведением при повторном открытии и выходе
- нативными меню, подключёнными к тому же реестру команд, что и в веб-клиенте
- соединением с выбранным сервером и кешированным состоянием входа
- необязательным подключением Remote Runtime для **This computer**

Всё остальное (Bot, сессии, память, рабочие пространства, каналы) живёт на сервере, к которому вы подключились. Рантаймы рабочих пространств настраиваются на стороне сервера; см. [Бэкенды рабочих пространств](./workspace-backends.md).

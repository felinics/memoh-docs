# Обзор самостоятельного развёртывания

Memoh работает как серверный стек; веб-клиент и настольное приложение — его клиенты. Сначала выберите серверный вариант, а затем решите, как вы будете к нему обращаться.

| Сценарий | Что выбрать | Почему |
|----------|--------|-----|
| Попробовать Memoh, ничего не устанавливая | [Memoh Cloud](https://memoh.ai) | Управляемый сервис, тот же продукт, не нужно держать собственный сервер. |
| Общий сервер, удалённый доступ, публичные/приватные каналы, стабильная работа в продакшене, несколько пользователей или арендаторов | [Server Deploy](./docker.md) | Стек Docker Compose поддерживает в рабочем состоянии бэкенд, веб-клиент, PostgreSQL (с pgvector для памяти) и рантайм рабочих пространств. |
| Нативное приложение на вашем компьютере, который при желании можно предоставить Bot как Computer | [Desktop](./desktop.md) | Нативный клиент, подключающийся к Cloud или вашему серверу; локальный сервер он не запускает. |

## Server Deploy

Выбирайте Server Deploy, когда Memoh должен быть доступен нескольким пользователям, работать непрерывно или подключаться к внешним каналам: Telegram, Discord, Feishu, WeChat, официальным аккаунтам WeChat, электронной почте и другим.

Начните с [Быстрого старта](../guides/quick-start.md) — это самый короткий путь, а полный справочник ищите в [Server Deploy](./docker.md).

## Desktop

Выбирайте Desktop, если хотите, чтобы Memoh вёл себя как нативное приложение с иконкой в трее и горячими клавишами, или если серверные Bot должны пользоваться файлами, оболочкой и браузером вашего компьютера. Desktop всегда подключается к серверу (Cloud или самостоятельно развёрнутому); см. [Desktop](./desktop.md).

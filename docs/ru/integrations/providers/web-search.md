# Провайдеры поиска

Memoh позволяет подключить Bot к различным поисковым системам, чтобы он мог искать в вебе актуальную информацию и внешние знания.

## Идея: знания в реальном времени

**Search Provider** (провайдер поиска) — это подключение к конкретному поисковому API (например, Brave, Google или Bing). После настройки он становится инструментом, которым Bot может пользоваться в разговоре.

---

## Поддерживаемые поисковые системы

Поисковые системы настраиваются на странице **Search Provider** в боковой панели.

| Поддерживаемые системы | Примечания |
|-------------------|-------|
| **Brave** | Настоятельно рекомендуется за приватность и производительность. |
| **Bing** | Индекс Microsoft; широкий глобальный охват. |
| **Google** | Всеобъемлющий веб-поиск. |
| **Tavily** | Создан специально для исследований с участием ИИ. |
| **SearxNG** | Подключение к собственному самостоятельно развёрнутому агрегатору поиска. |
| **DuckDuckGo** | Поиск с упором на приватность. |
| **Другие провайдеры**| Sogou, Serper, Jina, Exa, Bocha, Yandex. |

---

## Порядок настройки

### 1. Добавление провайдера поиска

1. Перейдите на страницу **Search Provider** в боковой панели.
2. Нажмите **Add Search Provider**.
3. Заполните поля:
    - **Name**: удобное имя (например, «My Brave Search»).
    - **API Key**: ваши учётные данные для API конкретной поисковой системы.
    - **Другие параметры**: в зависимости от системы могут понадобиться дополнительные настройки (например, `base_url` для SearxNG).

### 2. Управление провайдерами

- **Edit**: выберите провайдер в боковой панели и обновите его конфигурацию в форме справа.
- **Delete**: кнопка **Delete Provider** в форме настроек провайдера.

---

## Назначение провайдера поиска Bot

1. Перейдите на страницу **Bots** и выберите своего Bot.
2. Откройте вкладку **General**.
3. Найдите выпадающий список **Search Provider** и выберите созданный провайдер.
4. Нажмите **Save**.

---

## Взаимодействие с Bot

- Когда вопрос пользователя требует актуальной информации, Bot автоматически вызывает назначенный ему **Search Provider**.
- Bot обрабатывает результаты поиска, чтобы дать обоснованный и точный ответ.
- Несколько результатов поиска могут объединяться в один исчерпывающий ответ.

# Провайдеры генерации видео

Bot в Memoh могут генерировать видео через инструмент `generate_video`. Чтобы включить его, нужны две вещи:

1. **Видеопровайдер** хотя бы с одной видеомоделью, настроенный в **Settings → Integrations → Video**.
2. Модель **Video Generation Model**, назначенная Bot в **Bot Settings → Multimedia**.

Если Bot не назначена видеомодель, инструмент `generate_video` ему не предлагается.

---

## Поддерживаемые провайдеры

| Провайдер | Client Type | Base URL по умолчанию |
|----------|-------------|------------------|
| **OpenRouter** | `openrouter-video` | `https://openrouter.ai/api` |
| **ModelArk (BytePlus)** | `modelark-video` | `https://ark.ap-southeast.bytepluses.com/api/v3` |
| **Volcengine (Ark)** | `volcengine-video` | `https://ark.cn-beijing.volces.com/api/v3` |

Каждому провайдеру нужен **API Key**; **Base URL** необязателен — без него используется значение по умолчанию из таблицы выше.

Шаблоны из комплекта содержат актуальные пресеты моделей Seedance / Veo / Doubao-Seedance:

- **OpenRouter**: `bytedance/seedance-2.0`, `google/veo-3.1-fast`, `google/veo-3.1-lite`
- **ModelArk**: `dreamina-seedance-2-0-260128`, `dreamina-seedance-2-0-fast-260128`, `dreamina-seedance-2-5`
- **Volcengine**: `doubao-seedance-2-0-260128`, `doubao-seedance-2-0-fast-260128`, `doubao-seedance-2-5`

OpenRouter также поддерживает **Import Models** из своего живого каталога. ModelArk и Volcengine не отдают список моделей по сети, поэтому их модели берутся из шаблона или добавляются вручную.

---

## Настройка

1. Откройте **Settings → Integrations → Video**.
2. Добавьте провайдер из списка шаблонов (OpenRouter, ModelArk или Volcengine).
3. Введите API-ключ, меняйте base URL только при использовании нестандартной конечной точки и сохраните.
4. Проверьте раздел **Video Models**: если список пуст, импортируйте модели от провайдера или добавьте модель вручную.
5. Откройте у Bot **Settings → Multimedia** и выберите **Video Generation Model**.

---

## Как Bot этим пользуется

Просто попросите Bot сделать видео обычными словами. Под капотом:

- `generate_video` запускает **фоновую задачу** и сразу возвращает ID задачи; генерация обычно занимает минуты, и Bot проверяет прогресс своими инструментами фоновых задач.
- Инструмент принимает текстовый `prompt`, а также необязательные `duration_seconds`, `resolution` (например, `720p`/`1080p`), `aspect_ratio` (например, `16:9`, `9:16`, `1:1`), зависящий от провайдера `size` и `generate_audio`.
- Готовое видео скачивается в рабочее пространство Bot по пути `/data/generated-videos/<task_id>.mp4` (`.webm`/`.mov` — в зависимости от вывода провайдера).
- Видео **никуда не отправляется автоматически** — Bot доставляет его вложением к сообщению, а ещё его можно забрать с вкладки **Files** рабочего пространства.

Если в момент завершения генерации рабочее пространство недоступно, задача всё равно завершается — с предупреждением и URL результата от провайдера, но на диск ничего не сохраняется.

# Настройка канала DingTalk

Подключите своего Bot в Memoh к DingTalk для личных и групповых чатов: входящие события приходят через режим DingTalk Stream, а ответы и медиа отправляются через официальные API DingTalk.

::: warning Ограничения
- Ответы доставляются целыми сообщениями; потоковый вывод по токенам в DingTalk не поддерживается.
:::

## Предварительные условия

- Доступ к платформе разработчиков DingTalk вашей организации с правом создавать приложения.
- Публичный URL обратного вызова не нужен: входящие события приходят по Stream-соединению DingTalk, которое Memoh поддерживает автоматически.

## Шаги

### 1. Создайте приложение DingTalk

На платформе разработчиков DingTalk вашей организации:

1. Создайте или выберите приложение, которое будет выступать в роли Bot.
2. Включите для этого приложения возможность Bot / обмена сообщениями.
3. Скопируйте **App Key** и **App Secret**.
4. Выдайте приложению права на сообщения и опубликуйте его в организации, чтобы пользователи могли к нему обращаться.

### 2. Добавьте канал в Memoh

В Memoh:

1. Откройте вкладку **Platforms** нужного Bot.
2. Нажмите **Add Channel** и выберите **DingTalk**.
3. Заполните **App Key** и **App Secret**.
4. Нажмите **Save and Enable**.

Memoh поддерживает Stream-соединение с DingTalk автоматически — вставлять URL обратного вызова webhook никуда не нужно.

## Учётные данные

| Поле | Обязательное | Описание |
|-------|----------|-------------|
| **App Key** | Да | Ключ приложения DingTalk; копируется из учётных данных приложения на платформе разработчиков DingTalk. |
| **App Secret** | Да | Секрет приложения DingTalk; копируется там же. |

## Проверка

Отправьте Bot `/help` в личном чате или обратитесь к нему в групповом чате через @-упоминание с `/help`. Bot ответит списком команд — это подтверждает, что канал работает.

## Групповые чаты

Bot работает в групповых чатах DingTalk: чтобы получить ответ, упомяните его через @ в поддерживаемой группе.

## Отключение и смена учётных данных

Отключить или удалить канал можно в любой момент на вкладке **Platforms** нужного Bot. Чтобы сменить учётные данные, обновите **App Key** / **App Secret** в той же панели и сохраните.

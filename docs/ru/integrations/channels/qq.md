# Настройка канала QQ

Подключите своего Bot в Memoh к QQ через официальную Bot-платформу QQ: поддерживаются личные чаты, групповые чаты и треды (话题).

::: warning Ограничения
- На один аккаунт QQ можно создать не более 5 Bot.
- Ответы доставляются целыми блоками; потоковый вывод по токенам не поддерживается.
:::

## Предварительные условия

- Аккаунт QQ для входа на [QQ Bot Open Platform](https://q.qq.com/qqbot/openclaw/).

## Шаги

### 1. Создайте Bot QQ

На платформе QQ Bot Open Platform:

1. Откройте [QQ Bot Open Platform](https://q.qq.com/qqbot/openclaw/) и войдите с аккаунтом QQ.
2. Нажмите **Create Bot** (创建机器人) — согласование не требуется.
3. Скопируйте показанные на странице **AppID** и **AppSecret**. **AppSecret** отображается только один раз — сохраните его в надёжном месте.

> Официальные ресурсы: [QQ Bot Open Platform](https://q.qq.com/) · [документация QQ Bot](https://bot.q.qq.com/wiki/)

### 2. Добавьте канал в Memoh

В Memoh:

1. Откройте вкладку **Platforms** нужного Bot.
2. Нажмите **Add Channel** и выберите **QQ**.
3. Вставьте **AppID** и **AppSecret**.
4. При необходимости настройте необязательные параметры: **Markdown Support** и **Enable Input Hint** включены по умолчанию.
5. Нажмите **Save and Enable**.

## Учётные данные

| Поле | Обязательное | Описание |
|-------|----------|-------------|
| **AppID** | Да | Идентификатор приложения Bot; показывается на QQ Bot Open Platform при создании Bot. |
| **AppSecret** | Да | Секрет приложения Bot; показывается только один раз при создании. |
| **Markdown Support** | Нет | Включает форматирование Markdown (по умолчанию включено). |
| **Enable Input Hint** | Нет | Показывает индикатор набора текста, пока Bot готовит ответ (по умолчанию включено). |

## Проверка

Отправьте Bot `/help` в личном сообщении или обратитесь к нему в групповом чате через @-упоминание с `/help`. Bot ответит списком команд — это подтверждает, что канал работает.

## Групповые чаты

Bot работает в групповых чатах QQ и в тредах (话题): чтобы получить ответ, упомяните его в группе через @.

## Отключение и смена учётных данных

Отключить или удалить канал можно в любой момент на вкладке **Platforms** нужного Bot. Чтобы сменить учётные данные, обновите **AppID** / **AppSecret** в той же панели и сохраните.

## Частые вопросы {#faq}

### Я потерял AppSecret {#appsecret-reset}

**AppSecret** показывается только один раз — при создании Bot. Повторный просмотр на QQ Bot Open Platform принудительно сбрасывает его; после сброса обновите **AppSecret** в Memoh и сохраните.

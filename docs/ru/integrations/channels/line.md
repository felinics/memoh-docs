# Настройка канала LINE

Подключите своего Bot в Memoh к официальному аккаунту LINE: пользователи добавляют связанный аккаунт в друзья и общаются с Bot один на один.

::: warning Ограничения
- Только личные чаты. Сообщения из групп и многопользовательских комнат игнорируются — приглашать Bot в группу LINE бессмысленно.
- Вывод — только обычный текст; Markdown не отображается.
- Исходящие медиа ограничены изображениями PNG/JPEG. Изображения должны быть доступны из интернета по HTTPS и укладываться в лимиты LINE по размеру (10 МБ оригинал, 1 МБ превью); вложения, не являющиеся изображениями, отправить нельзя.
- Входящие аудио, видео, стикеры и геопозиции не обрабатываются. Входящие изображения должны размещаться на серверах самого LINE (обычный случай для фото, отправленных из приложения).
- Ответы приходят целыми сообщениями — LINE не поддерживает инкрементальный потоковый вывод, — а длинные ответы разбиваются на несколько сообщений по лимиту LINE в 5000 символов.
- Ответы доставляются через **Push API** LINE, поэтому они расходуют квоту push-сообщений вашего тарифа LINE.
:::

## Предварительные условия

LINE доставляет сообщения в Memoh через **webhook**, а серверы LINE также сами забирают исходящие изображения из вашего развёртывания, поэтому у Memoh должна быть публичная конечная точка HTTPS:

- Установите `MEMOH_WEBHOOK_PUBLIC_BASE_URL` в ваш публичный HTTPS origin (без пути, порта и внутренних адресов), или
- Включите профиль Cloudflare Quick Tunnel в стеке server deploy — тогда Memoh получит публичный URL автоматически.

## Шаги

### 1. Создайте канал LINE Messaging API

В LINE Developers Console:

1. Откройте [LINE Developers Console](https://developers.line.biz/console/).
2. Создайте провайдера (или выберите существующего), затем создайте канал **Messaging API**. Он будет связан с официальным аккаунтом LINE.
3. В разделе **Basic settings** скопируйте **Channel secret**.
4. На вкладке **Messaging API** выпустите и скопируйте **Channel access token** (долгоживущий).

> Официальное руководство: [LINE Messaging API - Getting Started](https://developers.line.biz/en/docs/messaging-api/getting-started/)

### 2. Добавьте канал в Memoh

В Memoh:

1. Откройте вкладку **Platforms** нужного Bot.
2. Нажмите **Add Channel** и выберите **LINE**.
3. Вставьте **Channel Secret** и **Channel Access Token**.
4. Нажмите **Save** (или **Save and Enable**). URL обратного вызова webhook генерируется только после сохранения настроек.

### 3. Зарегистрируйте webhook

В Memoh после сохранения панель показывает доступный только для чтения **WebHook Callback URL** вида:

```text
https://<your-public-base>/channels/line/webhook/<config_id>
```

Зарегистрировать его можно двумя способами:

- Нажмите **Set in LINE** — Memoh запишет адрес webhook в ваш канал LINE напрямую через Messaging API. Сначала сохраните несохранённые изменения, иначе кнопка вернёт ошибку.
- Или нажмите **Copy** и вручную вставьте URL в **Messaging API → Webhook URL** в LINE Developers Console.

Затем в LINE Developers Console убедитесь, что для канала включён параметр **Use webhook**.

Memoh проверяет подписи входящих webhook по вашему **Channel Secret** и дедуплицирует события в течение 24 часов.

## Учётные данные

| Поле | Обязательное | Описание |
|-------|----------|-------------|
| **Channel Secret** | Да | Копируется из **Basic settings** канала Messaging API. |
| **Channel Access Token** | Да | Долгоживущий токен, выпущенный на вкладке **Messaging API**. |

## Проверка

Добавьте связанный официальный аккаунт LINE в друзья, затем отправьте Bot `/help` в чате один на один. Bot ответит списком команд — это подтверждает, что канал работает.

## Отключение и смена учётных данных

Отключить или удалить канал можно в любой момент на вкладке **Platforms** нужного Bot. Чтобы сменить учётные данные, обновите **Channel Secret** / **Channel Access Token** в той же панели и сохраните.

## Частые вопросы {#faq}

### Панель предупреждает, что публичный базовый URL недоступен {#no-public-base-url}

Без публичного HTTPS origin невозможно построить URL обратного вызова webhook. Сначала настройте `MEMOH_WEBHOOK_PUBLIC_BASE_URL` или Cloudflare Quick Tunnel, как описано в предварительных условиях.

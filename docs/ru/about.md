# О Memoh

Memoh v0.13 — мультиагентная платформа с открытым исходным кодом. Она позволяет запускать на одной машине несколько ИИ-агентов, и каждый агент получает собственное рабочее пространство, браузер, сеть, инструменты и долговременную память.

Агенты могут общаться через Telegram, Discord, Slack, Feishu, WeChat, DingTalk и другие каналы — а также напрямую в приложении Memoh. Они умеют запоминать контекст, управлять браузером или рабочим столом, вызывать инструменты MCP, устанавливать навыки и коннекторы, выполнять задачи по расписанию и соблюдать правила доступа, заданные для каждого Bot.

Предпочитаете управляемый вариант вместо собственного развёртывания? [Memoh Cloud](https://app.memoh.net) — тот же продукт в виде облачного сервиса.

## Форматы поставки

### Desktop

Desktop — нативный клиент для Memoh Cloud или самостоятельно развёрнутого сервера. Он оборачивает тот же клиентский интерфейс в нативное окно с системным треем и горячими клавишами и может зарегистрировать компьютер, на котором работает, как Computer, доступный Bot. Локальный сервер он не запускает.

### Server Deploy

Server Deploy — для постоянной совместной работы. Используйте его, когда Memoh должен обслуживать нескольких пользователей, держать каналы онлайн, пока ваш компьютер не в сети, или работать как самостоятельно развёрнутый сервис. Стек Docker Compose включает бэкенд, веб-клиент, базу данных, сервисы памяти и рантайм рабочих пространств.

## Главное в v0.13

### Рабочие пространства агентов

Каждый Bot может использовать изолированное контейнерное рабочее пространство с файлами, командами, хостингом MCP, доступом к сети, браузером с графическим интерфейсом (headed) и графическим рабочим столом. Локальные и настольные конфигурации могут также использовать доверенные локальные рабочие пространства, когда доступ на уровне хоста даётся осознанно.

### Клиент

Клиент теперь покрывает больше повседневных задач: настройку Bot, сессии, провайдеров, каналы, файлы рабочего пространства, панели терминала и рабочего стола, Supermarket, Hooks, задачи по расписанию, контроль доступа и пользовательские настройки. В v0.13 также появилась поддержка английского, упрощённого китайского и японского языков интерфейса.

### Hooks, расписания и автоматизация

Hooks позволяют Bot выполнять небольшие правила автоматизации вокруг поддерживаемых событий, а Schedule поддерживает регулярную работу без активного чата. Навыки и коннекторы из Supermarket расширяют возможности Bot без написания кода.

### Контроль доступа

Контроль доступа разделён на права чата на стороне канала и права пользователей на стороне рабочего пространства. Владельцы Bot могут разрешать или блокировать участников канала, выдавать зарегистрированным пользователям роли рабочего пространства, а для случаев, где нужно более точное сопоставление, — использовать продвинутые правила ACL.

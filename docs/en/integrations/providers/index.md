# Providers

Providers connect Memoh to external capability backends. Configure them before assigning models, memory, speech, or search behavior to bots.

## Provider Types

- **[LLM Providers](./llm.md)**: Chat, embedding, image, and related model configuration.
- **[Memory Providers](./memory/index.md)**: Long-term memory storage and retrieval backends.
- **[TTS Providers](./tts/index.md)**: Speech synthesis providers and voices.
- **[Web Search Providers](./web-search.md)**: Search providers used by web access tools.

For product-level usage after provider setup, see **[Bot](../../guides/bot.md)** and **[Memory](../../guides/memory.md)**.

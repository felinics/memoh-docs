# Integrations

Integrations connect Memoh to external systems. Use this section when you want a bot to appear in messaging platforms or when you need to configure upstream providers for models, memory, speech, or search.

## Channels

Channels make bots reachable outside the web app.

- **[Channels Overview](./channels/index.md)**: Supported platforms and general setup flow.
- **[Slack](./channels/slack.md)**, **[Telegram](./channels/telegram.md)**, **[Feishu](./channels/feishu.md)**, **[Discord](./channels/discord.md)**, **[WeChat](./channels/weixin.md)**, and more.

## Providers

Providers connect Memoh to external capability backends.

- **[LLM Providers](./providers/llm.md)**: Configure upstream APIs, client types, and model roles.
- **[Memory Providers](./providers/memory/index.md)**: Choose built-in memory, Mem0, or OpenViking.
- **[TTS Providers](./providers/tts/index.md)**: Configure speech synthesis providers and models.
- **[Web Search Providers](./providers/web-search.md)**: Configure search provider access.

## Product Guides

After integrations are configured, use **[Guides](../guides/index.md)** for bot setup, sessions, memory operations, tools, and daily workflows.

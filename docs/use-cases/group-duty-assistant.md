# Group On-Call Assistant

**Owns:** secretary duty in a team group: answers when mentioned and posts a daily recap.

**Uses:** [Platforms](../integrations/channels/index.md) · [Sessions](../guides/sessions.md) · [Access Control](../guides/access.md) · [Scheduled Tasks](../guides/schedule.md)

## Start with

> Once you join this group: when someone mentions you, summarize the day's discussion and open items. Every day at 6pm, post a recap organized as decisions / to-dos / open questions. Post only in this group — never message anyone privately.

## How it runs

Use the "group only" [Access Control](../guides/access.md) preset to fence its territory. In discuss sessions the bot decides for itself whether it has anything worth saying, so it will not flood the channel.

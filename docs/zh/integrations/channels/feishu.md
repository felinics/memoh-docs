# 飞书（Lark）

通过飞书开放平台接入，让企业 Bot 在群聊和私聊里与用户交互。

## 前提条件

- 一个能登录 [飞书开放平台](https://open.feishu.cn/app)、可创建企业自建应用的账号。
- 一个 Memoh Bot；渠道在它的 **平台** 标签页里配置。

## 步骤

### 1. 在飞书开放平台创建自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app) 并登录。
2. 点 **创建企业自建应用**，填名称与简介后创建。
3. 左侧进入 **凭证与基础信息**。
4. 复制 **App ID** 和 **App Secret**。

### 2. 在飞书开放平台启用 Bot 能力

进入 **应用能力** → **Bot**，点启用。

### 3. 在飞书开放平台开权限

1. 进入 **应用能力** → **权限管理**。
2. 至少开启：
   - `im:message`（收发消息）
   - `im:chat`（群信息等）
3. 组织有要求时，点 **申请权限** 提交。

### 4. 在 Memoh 添加飞书渠道（默认：长连接）

1. 打开 Bot 的 **平台** 标签页，添加 **飞书** 渠道。
2. **入站方式** 保持默认的 `websocket`。
3. 填 **App ID**、**App Secret**；使用国际版 Lark 时把 **区域** 切到 `lark`。
4. 点 **Save**。消息经飞书 **WebSocket 长连接** 送达，无需公网回调地址，也不用配置事件订阅。

### 5. 可选：改用 Webhook 入站

服务端可被公网访问、且更希望走事件回调时，再选这种方式。

::: tip
这一步会在 Memoh 和飞书后台之间往返：Memoh 生成回调 URL 后要贴回 **事件订阅** 页，先别关飞书后台。
:::

1. 在 Memoh 把 **入站方式** 改为 `webhook`；除 **App ID**、**App Secret** 外，再填入与飞书后台事件订阅一致的 **Encrypt Key** 和 **Verification Token**。
2. 点 **Save**，页面会生成 **Webhook 回调 URL**，复制它。
3. 回到飞书后台，进入 **应用配置** → **事件订阅**，把 URL 填到 **请求地址** 并保存。
4. 添加 **接收消息**（`im.message.receive_v1`）等事件。

> 官方说明：[飞书自定义机器人](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)

### 6. 在飞书开放平台发布应用

1. 进入 **应用发布** → **版本管理与发布**。
2. 点 **创建版本**，填写信息并提交审批。
3. 审批通过并发布后，Bot 才能在租户里正常使用。

## 凭据

| 字段 | 说明 |
|------|------|
| **App ID** | 在飞书开放平台 **凭证与基础信息** 页获取。 |
| **App Secret** | 与 App ID 同页获取。 |
| **区域** | 使用国际版 Lark 时切到 `lark`。 |
| **入站方式** | `websocket`（默认，长连接）或 `webhook`。 |
| **Encrypt Key** | 仅 webhook 模式需要，须与飞书后台事件订阅设置一致。 |
| **Verification Token** | 仅 webhook 模式需要，须与飞书后台事件订阅设置一致。 |

## 验证

在飞书里私聊 Bot，发送 `/help`。Bot 回复命令列表即说明渠道已生效。

## 群聊

飞书支持群聊。把 Bot 加进群后，@它即可在群里对话。

## 停用与更换凭据

在 Bot 的 **平台** 标签页可以随时停用或移除该渠道。更换凭据时，更新对应字段（如 **App Secret**）并保存即可。

## 常见问题 {#faq}

### 渠道配好了，Bot 却没反应 {#app-not-published}

自建应用要先发布：在飞书开放平台 **应用发布** → **版本管理与发布** 里创建版本并提交审批，审批通过并发布后 Bot 才能在租户里正常使用。

### 权限要走审批 {#permission-approval}

部分组织对应用权限有审批流程：在 **应用能力** → **权限管理** 里点 **申请权限** 提交即可。

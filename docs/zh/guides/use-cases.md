# 使用场景

组合多种 Memoh 功能解决实际问题的即用型示例。

好的 Bot 分工，是**负责一个可重复的结果**，而不是"大概管一类问题"。下面每个场景都给出：Bot 负责什么、用到哪些功能、以及一句可以直接发给它的起手指令。所有示例都从只读工作开始——先看它做得对不对，再逐步放权。

## 晨间简报

**它负责：** 每个工作日开始前，把你关心的信息汇成一条消息。

**用到：** [定时任务](./schedule.md) · [搜索提供方](../integrations/providers/web-search.md) · [平台](../integrations/channels/index.md)

**从这句开始：**

> 每个工作日早上 8 点，汇总我关注的这几个仓库过去 24 小时的 release 和重要 issue，加上今天的天气，整理成一条简报发给我。每条信息注明来源，不确定的内容直接说不确定，不要编造。

Bot 自带 `schedule` 工具，你用自然语言说清楚时间，它会自己登记 cron。先用 **Max Calls** 限制试跑几次，确认格式满意再放开。

## 发版盯守

**它负责：** 盯住一个你在等的外部变化，发生时第一时间主动找你。

**用到：** [定时任务](./schedule.md) · [工作区](./container.md) · [平台](../integrations/channels/index.md)

**从这句开始：**

> 盯着这个项目的发布页，每 30 分钟检查一次。出了新版本就把变更内容整理成 Markdown 存进工作区，并在 Telegram 上提醒我一句。只做整理，不要执行任何升级或安装。

"你不在的时候它也在"是定时任务加主动消息的组合：到点检查、有变化才说话。同类玩法还有盯价格、盯库存、盯文档更新。

## 群聊值班助理

**它负责：** 在团队群里当值班秘书：被 @ 时答疑，每天固定时间发纪要。

**用到：** [平台](../integrations/channels/index.md) · [会话](./sessions.md) · [访问控制](./access.md) · [定时任务](./schedule.md)

**从这句开始：**

> 接入这个群之后：有人 @ 你就总结当天讨论要点和待办；每天 18 点主动发一份当日纪要，按"结论 / 待办 / 未决"三段整理。纪要只发在群里，不要私聊任何人。

用 [访问控制](./access.md) 的"仅群聊"预设限定它的活动范围。讨论（discuss）会话里 Bot 会自己判断该不该说话，不会刷屏。

## 数据表格的日常维护

**它负责：** 一份活的数据文件：建表、定期更新、有异动先报告。

**用到：** [工作区](./container.md) · [文件](./files.md) · [定时任务](./schedule.md)

**从这句开始：**

> 在工作区建一个竞品价格表（CSV）。每天早上检查一次各家官网价格，把变化追加写进表格；有降价先发消息告诉我。只维护这份文件，不要对外发送任何内容给别人。

工作区是真实的文件系统加终端（预装 Python、Node.js、uv），清洗 CSV、跑脚本、生成报表都在里面完成，产出物随时可以在 **文件** 里查看。

## 带登录墙的网页任务

**它负责：** 需要"看着屏幕"的网页操作：后台核对、表单流程、OAuth 授权。

**用到：** [Browser / Computer Use](./browser-computer-use.md) · [工作区](./container.md)（可视化桌面）

**从这句开始：**

> 打开我们的后台控制台，按我给你的清单逐项核对配置，每一项截图存进工作区。遇到登录、验证码或任何拿不准的画面就停下来等我接管桌面，我处理完你再继续。全程只读，不要修改任何设置。

可视化桌面是双向的：你能在桌面面板里看着它操作，也能随时接管键鼠输密码，再把控制权交回去。浏览器会话保留在工作区里，下次任务免登录。

## 云端写码与预览

**它负责：** 在自己的工作区里写一个小项目，跑起来给你看。

**用到：** [Agents / ACP](./acp.md) · [工作区](./container.md) · [技能](./skills.md)

**从这句开始：**

> 在工作区里做一个阅读清单网页：能添加、标记读完、按主题筛选。做好后把开发服务跑起来，给我预览方式。所有改动用 git 提交在本地，不要推送到任何远端。

习惯用 Claude Code 或 Codex？在 Bot 的 **Agent** 标签页接入你自己的订阅，它会在同一个工作区、同一批文件上继续干活。

## 记得住事的个人助理

**它负责：** 跨会话、跨平台地记住你的偏好和项目进展，接着上次继续。

**用到：** [长期记忆](./memory.md) · [平台](../integrations/channels/index.md) · [定时任务](./schedule.md)

**从这句开始：**

> 记住这些偏好：上午留给深度工作，会议尽量约下午；周报每周五下班前要成稿。以后帮我安排提醒和整理摘要时，先查记忆再动手；偏好拿不准就问我，不要猜。

配好 [记忆提供方](../integrations/providers/memory/builtin.md) 后，"上次那个 PR 后来怎么样了"这类问题它能直接接住。记忆攒多了用 **Compact** 做一次合并去重。

## 从示例到日常使用

1. **从只读开始。** 先让它"读并整理"，人工检查几次产出，再谈写入和执行。
2. **把约束写进指令。** 结果、来源、约束、形式、确认点——五件事说清楚（见 [快速开始](./quick-start.md)）。
3. **重复的流程存成 [技能](./skills.md)。** 一句话唤起整套动作，不用每次重打。
4. **稳定后再上 [定时任务](./schedule.md)。** 先用 Max Calls 试跑，确认无误再放开。
5. **写入和执行留在审批后面。** 即使流程已经很熟，对外动作也值得多看一眼。
6. **用 [访问控制](./access.md) 限定谁能使唤它。** 尤其是接入群聊的 Bot。
7. **让 [记忆](./memory.md) 沉淀偏好。** 纠正过的事不该再错第二次。

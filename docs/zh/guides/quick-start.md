# 快速开始

一份从零开始的完整教程：安装应用、登录、创建第一个 Bot、交给它真实工作，并在聊天平台上找到它。大约需要十五分钟。

## 前置条件

- 一台 macOS、Windows 或 Linux 电脑。
- 一个 [Memoh Cloud](https://app.memoh.net) 账号——登录时可以直接注册。

就这些。Memoh Cloud 内置了托管模型（DeepSeek、Kimi、GPT、Claude 等），上手不需要任何 API Key。

## 第 1 步：安装 Memoh

从 [下载页](https://memoh.ai/desktop) 下载对应平台的安装包——macOS（DMG）、Windows（安装程序）或 Linux（AppImage/deb/rpm）——然后打开它。

## 第 2 步：登录

在连接页选择 **Memoh Cloud** 并登录，没有账号就先注册一个。

## 第 3 步：创建第一个 Bot

进入 **Bot → 新建 Bot**，填写名称与显示名，然后在 **通用** 标签页选择对话模型。托管模型开箱即用。

接下来写它的指令。这一步最关键，也最容易出错——通常是写得太笼统。把一件事说清楚：

> **名称：** Digest
>
> **角色：** 每周阅读摘要
>
> **指令：** 收集我这一周发给你的文章。每周五整理成一份摘要，按主题分组：每篇一句话概括并附原始链接，最后加一节"值得再读"。原始链接保持不变。任何内容都不要公开发布。

职责单一的 Bot 能积累的有效上下文，远多于什么都干的 Bot。当工作确实分成不同角色时，请新建一个 Bot，而不是把这个越堆越重——每个 Bot 都有独立的工作区、记忆和配置。逐个标签页的说明见 [Bot](./working-with-bots.md)。

点击 **聊天** 打个招呼。收到回复就说明模型链路是通的。

## 使用自己的模型（BYOK）

托管模型之外，你随时可以自带模型（Bring Your Own Key）：

1. 在侧边栏打开 **模型服务商**，点击 **添加服务商**。
2. 选择模板（OpenAI、Anthropic、Gemini、DeepSeek、智谱、OpenRouter、Ollama 等），填入你的 API Key；OpenAI 兼容端点再补上对应的 Base URL。
3. 打开该服务商并**同步**模型列表，或手动添加至少一个对话模型，然后在 Bot 的 **通用** 标签页切换过去。

BYOK 的模型用量按你所选服务商的价格计费。编码智能体同理：在 Bot 的 **Agent** 标签页，用你自己的订阅或 API Key 登录 Claude Code、Codex。各家的字段与注意事项见 [模型服务商](../integrations/providers/llm.md)。

## 第 4 步：交给它第一个任务

一个好的首次请求会回答五个问题：

| 要素 | 它回答的问题 |
|------|------------|
| **结果** | 做完之后应该存在什么？ |
| **来源** | 涉及哪些文件、网站或对话？ |
| **约束** | 什么不能碰，什么需要你批准？ |
| **形式** | 结果以什么形式交付？ |
| **确认点** | 什么时候该停下来跟你确认？ |

想在几分钟内看到结果、又不需要任何外部登录，可以上传一份文档试试：

```text
把这份文档总结成五个要点。另起一节，列出其中所有的日期、决定和待解决问题，
并标注每条来自哪一页或哪一节。不要修改原文件。
```

Bot 会在自己的工作区里读取文件，并把结果写回对话。它产出的一切都留在工作区，你可以在 [文件](./files.md) 里浏览和编辑。

## 第 5 步：让它用上工作区和浏览器

工作区是 Bot 干活的地方。它有 Linux 文件系统、终端和预装工具链（Python、Node.js、uv、npm），数据清洗、脚本、构建都能直接跑：

```text
把我刚上传的 CSV 里 email 列为空的行全部删掉。
给我清洗后的文件，并告诉我删了多少行。
```

当任务需要真实浏览器时——比如无头模式下会出错的站点，或需要登录才能访问的页面——在 Bot 的 **桌面** 标签页启用可视化桌面。启动后，Bot 会驱动一个有头 Chrome，你可以在桌面面板里看着它操作。

遇到登录墙时，你可以自己接管屏幕：输入密码、通行密钥或一次性验证码，然后把控制权交还给它。浏览器会话保留在该工作区中，后续任务依然是登录状态。

::: warning 按需授权
工作区权限是分级的：仅聊天、读文件、写文件、执行命令、管理容器。任务需要哪一级就给哪一级，不要多给。参见 [访问控制](./access.md)。
:::

详见 [工作区](./container.md) 与 [浏览器 / 电脑操作](./browser-computer-use.md)。

## 第 6 步：在聊天平台上找到它

Bot 在你本来就聊天的地方最有用。

1. 打开 Bot 的 **平台** 标签页，点击 **添加**。
2. 选择平台——Telegram、Slack、Discord、飞书、钉钉、企业微信、微信、QQ 或 LINE——并填入该平台的凭据。
3. 从该平台给它发消息。第一条消息会创建会话；发送 `/help` 可以看到可用的 [斜杠命令](./slash-commands.md)。

从此你可以在手机上派活，然后在同一个对话里收结果。各平台的具体配置见 [渠道](../integrations/channels/index.md)。

## 第 7 步：复盘，然后固化下来

有问题就直接说。把纠正写成长期规则，而不是一次性修补：

```text
以后所有的摘要都用这个格式：按主题分组，每篇一行，链接放在行内，
最后加一节"值得再读"。
```

当一套流程稳定下来后，就别再重复输入了：

- 存成 [技能](./skills.md)，以后一句话唤起整套流程。
- 变成 [定时任务](./schedule.md)，按 cron 自动运行，完全不需要聊天。
- 用 [长期记忆](./memory.md) 把你的偏好和项目上下文带进之后的每一次会话。

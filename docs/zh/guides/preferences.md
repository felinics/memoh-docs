# 偏好设置

Memoh v0.13 提供客户端级别的用户偏好设置。它们会改变当前设备配置档里的界面观感和快捷键行为，不会改变 Bot 的人格、模型、工具、记忆或访问规则。

打开 **Settings**，在 **Appearance** 调整视觉偏好，在 **Keyboard** 调整快捷键。

---

## 外观

**Appearance** 页面分为界面、字体与字号、代码高亮、图表几个部分。修改会立即生效。

### 界面

| 设置 | 作用 |
|------|------|
| **Language** | 设置界面语言。v0.13 包含 English、简体中文和日本語。如果还没有手动选择，Memoh 会根据浏览器语言识别英文、中文或日文，并在无法识别时回退到英文。 |
| **Theme** | 选择 Light、Dark 或 System。System 会跟随操作系统或浏览器的颜色模式。 |
| **Color Scheme** | 更换品牌元素、状态颜色和界面控件使用的强调色方案。可选 Memoh、Ocean、Forest、Rose、Amber。 |

这里的语言只影响 Memoh 界面。Bot 回复时使用什么语言，仍在 Bot 设置里配置。

### 字体与字号

如果界面太小、太大，或你想换代码字体，可以在这里调整。

| 设置 | 影响范围 | 范围 / 默认值 |
|------|----------|---------------|
| **UI Font Size** | 常规界面文字和控件 | `12`-`20` px，默认 `16` |
| **Code Font Size** | 代码编辑器、Markdown 代码块和终端文字 | `11`-`20` px，默认 `13` |
| **UI Font Family** | 主界面字体 | 默认 `system-ui, sans-serif` |
| **Code Font Family** | 代码、编辑器和终端字体栈 | 默认 `ui-monospace, monospace` |

字体字段接受普通 CSS 风格的字体栈，例如 `Inter, system-ui, sans-serif` 或 `"JetBrains Mono", ui-monospace, monospace`。对应字体需要已经存在于你的设备或浏览器环境中。清空字段，或填入默认值，可以回到 Memoh 默认字体栈。

### 代码高亮

Memoh 使用 Shiki 主题渲染代码高亮。你可以分别选择浅色模式和深色模式下的主题：

| 设置 | 影响范围 |
|------|----------|
| **Light theme** | 界面处于浅色模式时的代码块和编辑器 |
| **Dark theme** | 界面处于深色模式时的代码块和编辑器 |

主题选择器会搜索内置 Shiki 主题列表，并显示实时预览，方便你在离开页面前对比浅色和深色选择。

### 图表

聊天和 Markdown 预览中渲染的 Mermaid 图表会使用 **Mermaid Theme** 偏好。

| 主题 | 行为 |
|------|------|
| **Auto** | 跟随当前界面模式。 |
| **Default** | 使用 Mermaid 默认浅色主题。 |
| **Dark** | 使用 Mermaid 深色主题。 |
| **Forest** | 使用 Mermaid forest 主题。 |
| **Neutral** | 使用 Mermaid neutral 主题。 |

如果某个图表已经写了自己的 Mermaid 初始化指令，它可能会保留文档作者指定的主题；这适合需要固定图表风格的文档。

## 快捷键

**Keyboard** 页面会按作用域列出可编辑快捷键。点击某一行的 **Edit**，按下新的组合键，然后保存。

### 默认快捷键

macOS 上显示为 `Cmd`，Windows 和 Linux 上显示为 `Ctrl`。

| 动作 | 默认快捷键 | 作用域 |
|------|------------|--------|
| 关闭当前工作区标签页 | 桌面应用中为 `Cmd/Ctrl + W`。在普通浏览器里，浏览器会保留原生关闭标签页行为。 | 全局 |
| 保存当前文件 | `Cmd/Ctrl + S` | 全局 |
| 切换侧边栏 | `Cmd/Ctrl + B` | 全局 |
| 打开设置 | `Cmd/Ctrl + K` | 全局 |
| 关闭媒体灯箱 | `Esc` | 媒体灯箱 |
| 上一张媒体 | `Left Arrow` | 媒体灯箱 |
| 下一张媒体 | `Right Arrow` | 媒体灯箱 |

全局快捷键在应用内普遍生效。媒体灯箱快捷键只在媒体预览覆盖层打开时生效。

### 修改规则

保存快捷键前，Memoh 会先检查组合键：

- `Cmd/Ctrl + W`、`Cmd/Ctrl + Q`、`Cmd/Ctrl + T`、`Cmd/Ctrl + N` 保留给浏览器或操作系统。
- 全局快捷键必须包含 `Cmd/Ctrl` 或 `Alt`，避免普通输入时误触应用命令。
- 同一作用域内，两条快捷键不能使用同一个组合键。
- 不同作用域可以共用组合键，但 Memoh 会提示警告，因为只有当前活跃的作用域会处理它。

用某一行的重置按钮可以恢复单个快捷键。用 **Reset all** 可以清空所有自定义快捷键。

---

## 实用说明

- 外观和快捷键是个人 UI 偏好，不会影响其他用户或 Bot。
- 偏好保存在当前设备/浏览器配置档里，换浏览器或换机器后可能需要重新设置。
- 如果试字体或快捷键后界面不合预期，可以回到同一页面重置对应字段或快捷键。

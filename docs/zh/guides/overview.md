# Memoh 概览

Memoh 给每个 Bot 一台自己的云电脑：带真实文件系统和终端的工作区、可以看见和接管的桌面浏览器，以及跨会话的长期记忆。你的笔记本合上之后，它照常工作。

和 Bot 协作的方式就是给它发消息。在 Memoh 应用里聊，或者把它接到 Telegram、Slack、Discord、飞书、钉钉、企业微信、微信、QQ、LINE。无论从哪个入口进来，都是同一个 Bot 和同一份记忆。

上手只需要下载应用并登录 Memoh Cloud。托管模型（DeepSeek、Kimi、GPT、Claude 等）开箱即用；想换自己的 API Key 或模型服务，见 [BYOK](./quick-start.md#使用自己的模型-byok)。

## Memoh 有什么不同

- **一台真实的电脑，不是一次性沙盒。** 写过的文件、装过的运行时都留在 [工作区](./container.md) 里，周一建的东西周五还能接着用。
- **一块你能看见的屏幕。** Bot 在可视化桌面里操作真实浏览器；遇到登录或验证码，你[接管键鼠](./browser-computer-use.md)处理完再交还给它。
- **记得住。** [长期记忆](./memory.md) 跨会话、跨渠道生效，纠正过一次的偏好不用再说第二遍。
- **你不在它也在跑。** [定时任务](./schedule.md) 按 cron 触发，结果发到你接入的渠道；到点检查、有变化才说话。
- **自带你的编码智能体。** 通过 [ACP](./acp.md) 把 Claude Code、Codex 装进同一个工作区，用你自己的订阅。

## 一个 Bot 负责一件事

每个 Bot 都有独立的工作区、记忆、渠道和权限边界，互不可见。工作确实分成不同角色时，就多建一个 Bot，而不是把一个越堆越重。谁能和 Bot 聊天、谁能读写它的文件、谁能执行命令，都在 [访问控制](./access.md) 里按级别授予——需要哪级给哪级。

## 第一个任务怎么交

挑一件你每周都在手动做的小事，说清楚结果、来源和边界：

> 每周五 17:00，把我这一周发给你的链接和文件整理成一份周报，按主题分组、每条一句话，存进工作区并把摘要发到这个对话。只整理我发给你的内容，不要外发给任何人。

Bot 会自己登记定时任务并按周交付。先从只读的活儿开始，检查过几次产出，再逐步放开写入和执行——更多现成搭配见 [使用场景](./use-cases.md)。

## 常见问题

**我关掉电脑，它还会跑吗？**

会。Bot 运行在云端工作区里，定时任务照常触发，渠道消息照常回复。

**可以建几个 Bot？**

取决于订阅计划。每个 Bot 都是独立的：自己的工作区、记忆和权限，删除一个不影响其他。

**我的文件放在哪？**

在该 Bot 的隔离容器工作区里（`/data`），跨会话保留，可在 [文件](./files.md) 里随时查看和编辑。

**能用自己的模型吗？**

能。在模型服务商里加自己的 API Key（见 [BYOK](./quick-start.md#使用自己的模型-byok)），编码智能体则在 Bot 的 **Agent** 标签页登录你自己的 Claude Code / Codex 订阅。

**订阅和计费的问题去哪问？**

[帮助中心](https://memoh.ai/help)：套餐、credits、账号问题，以及联系 Memoh 团队的入口。

# 发版盯守

**它负责：** 盯住一个你在等的外部变化，发生时第一时间主动找你。

**用到：** [定时任务](../guides/schedule.md) · [工作区](../guides/container.md) · [平台](../integrations/channels/index.md)

## 从这句开始

> 盯着这个项目的发布页，每 30 分钟检查一次。出了新版本就把变更内容整理成 Markdown 存进工作区，并在 Telegram 上提醒我一句。只做整理，不要执行任何升级或安装。

## 它是怎么跑起来的

"你不在的时候它也在"是定时任务加主动消息的组合：到点检查、有变化才说话。同类玩法还有盯价格、盯库存、盯文档更新。

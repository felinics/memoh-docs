## 从这句开始

> 在工作区里做一个阅读清单网页：能添加、标记读完、按主题筛选。做好后把开发服务跑起来，给我预览方式。所有改动用 git 提交在本地，不要推送到任何远端。

## 它是怎么跑起来的

习惯用 Claude Code 或 Codex？在 Bot 的 **Agent** 标签页接入你自己的订阅，它会在同一个工作区、同一批文件上继续干活。

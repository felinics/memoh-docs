## 从这句开始

> 打开我们的后台控制台，按我给你的清单逐项核对配置，每一项截图存进工作区。遇到登录、验证码或任何拿不准的画面就停下来等我接管桌面，我处理完你再继续。全程只读，不要修改任何设置。

## 它是怎么跑起来的

可视化桌面是双向的：你能在桌面面板里看着它操作，也能随时接管键鼠输密码，再把控制权交回去。浏览器会话保留在工作区里，下次任务免登录。

# 数据表格的日常维护

**它负责：** 一份活的数据文件：建表、定期更新、有异动先报告。

**用到：** [工作区](../guides/container.md) · [文件](../guides/files.md) · [定时任务](../guides/schedule.md)

## 从这句开始

> 在工作区建一个竞品价格表（CSV）。每天早上检查一次各家官网价格，把变化追加写进表格；有降价先发消息告诉我。只维护这份文件，不要对外发送任何内容给别人。

## 它是怎么跑起来的

工作区是真实的文件系统加终端（预装 Python、Node.js、uv），清洗 CSV、跑脚本、生成报表都在里面完成，产出物随时可以在 **文件** 里查看。

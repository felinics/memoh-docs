# 群聊值班助理

**它负责：** 在团队群里当值班秘书：被 @ 时答疑，每天固定时间发纪要。

**用到：** [平台](../integrations/channels/index.md) · [会话](../guides/sessions.md) · [访问控制](../guides/access.md) · [定时任务](../guides/schedule.md)

## 从这句开始

> 接入这个群之后：有人 @ 你就总结当天讨论要点和待办；每天 18 点主动发一份当日纪要，按"结论 / 待办 / 未决"三段整理。纪要只发在群里，不要私聊任何人。

## 它是怎么跑起来的

用[访问控制](../guides/access.md)的"仅群聊"预设限定它的活动范围。讨论（discuss）会话里 Bot 会自己判断该不该说话，不会刷屏。

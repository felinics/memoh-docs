# 晨间简报

**它负责：** 每个工作日开始前，把你关心的信息汇成一条消息。

**用到：** [定时任务](../guides/schedule.md) · [搜索提供方](../integrations/providers/web-search.md) · [平台](../integrations/channels/index.md)

## 从这句开始

> 每个工作日早上 8 点，汇总我关注的这几个仓库过去 24 小时的 release 和重要 issue，加上今天的天气，整理成一条简报发给我。每条信息注明来源，不确定的内容直接说不确定，不要编造。

## 它是怎么跑起来的

Bot 自带 `schedule` 工具，你用自然语言说清楚时间，它会自己登记 cron。先用 **Max Calls** 限制试跑几次，确认格式满意再放开。
